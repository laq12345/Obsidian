# Piezo1 通道的结构：哺乳动物机械敏感阳离子通道的"三叶螺旋桨"

> **论文**：Ge J, Li W, Zhao Q, Li N, Chen M, Zhi P, Li R, Gao N, Xiao B, Yang M. Architecture of the mammalian mechanosensitive Piezo1 channel. *Nature*. 2015;527(7576):64-69.

> **机构**：清华大学（清华–北大生命科学联合中心、生命科学学院、药学院）

> **相关笔记**：[[20813920]]（Piezo1/2 的功能鉴定，2010）｜ [[32744386]]（肺泡上皮 ATI）｜ [[31186359]]（肺内皮）｜ [[31435009]]（髓系免疫）｜ [[39664395]]（VILI 中 MSICs 系统综述）

## 一句话总结
本文解出了**全长小鼠 Piezo1（2547 个氨基酸）在 4.8 Å 分辨率下的冷冻电镜结构**，第一次看清这个"机械敏感通道"长什么样：它是一个**同源三聚体**（约 900 kDa），形似**三叶螺旋桨**——三个**叶片**和中央**帽**伸在胞外，**跨膜区每亚基有 14 个跨膜段**，中央围成**离子孔道**，三根约 80 Å 的**梁**在胞内把外周与中心连接起来。据此作者提出：**Piezo1 用外周区域"感受力"，再通过梁把信号传到中央孔道"开门"**。同时纠正了此前"Piezo1 是四聚体"的判断。

## 为什么要做这个研究
- Piezo1/2 已被确认为机械敏感阳离子通道的**成孔亚基**（[[20813920]]），功能极其重要：Piezo2 管**轻触觉**；Piezo1 管**血流剪切力与血管发育、红细胞功能、细胞迁移与分化**；人类 *PIEZO1/PIEZO2* 突变可致遗传性干瘪细胞增多症、远端关节挛缩症 5 型、Gordon 综合征、Marden–Walker 综合征。
- 但**结构完全未知**：其序列与已知任何通道家族（电压/配体门控、TRP、细菌 MscL/MscS、双孔钾通道）**都不同源**，蛋白又大（>2500 残基）、预测跨膜段极多。
- **四个待答问题**：几个亚基？整体什么形状？哪些部分在胞外/胞内？孔道和"感受力"的部位在哪里？

## 怎么做（方法要点）

| 步骤 | 关键做法 |
|---|---|
| 蛋白制备 | 人/小鼠/果蝇 Piezo1 全长与截短体，C 端接 GST（含酶切位点）；HEK293T 表达；**大量去垢剂筛选**后选定 **C12E10** |
| 定寡聚态 | 凝胶过滤 + Native PAGE 免疫印迹 + 负染电镜二维分类（比较 GST 融合、切标签、Flag 三种样品） |
| 冷冻电镜 | Titan Krios 300 kV + K2 直接电子探测器（像素 1.32 Å）；RELION 做对称自由（C1）与 C3 限制的重构 |
| 建模 | 对跨膜段/梁/胞内域建 **492 aa 多聚丙氨酸模型**；再结合序列比对与二级结构预测配位 |
| 帽的验证 | 单独表达 **CED（2214–2457）** 解晶体结构（碘单波长反常散射定相）；并做 **Δ2219–2453 缺失突变体**电镜 |
| 拓扑验证 | **活细胞**中用抗 Flag 抗体标记：Flag 放在 CED 柔性环（A2419 后）vs 放在蛋白 C 端 |

## 发现了什么（按 6 个问题组织）

### ① 是几个亚基？→ **三聚体**（不是四聚体）
- 切掉 GST 标签的 Piezo1 在 Native PAGE 上主要在 **900 kDa**（三聚体 876 kDa）；带 GST 时为 **1200 kDa**（实为"三聚体的二聚体"1908 kDa，因 **GST 自身会二聚化**）。
- 负染电镜：GST 融合体呈"二聚体样"排布；**去标签后可见清晰三重对称**。
- **纠正旧文献**：此前基于 1200 kDa 附近异常迁移判为四聚体——大蛋白 + 多跨膜段 + 去垢剂会影响迁移率。
- 作者保留余地：不能完全排除膜上存在其他寡聚状态。

### ② 整体长什么样？→ **三叶螺旋桨**
- 俯视直径 **200 Å**，高 **155 Å**。
- **三个远端叶片（blade）**：厚实、呈超螺旋排布，表面还有螺旋状起伏。
- **一个中央帽（cap）**：悬在跨膜核上方，中间有 **约 8 Å 的缝隙**。
- **三根梁（beam）**：长约 **80 Å**，像双链卷曲螺旋，把跨膜区远端/叶片连到三聚体**底面中心**。
- 跨膜区下方还有一块紧密的胞内结构域。

### ③ 哪部分在胞外、哪部分在胞内？→ **帽＝CED 在胞外，C 端在胞内**
- 缺失 2219–2453 段 → 电镜二维分类中**帽消失**，证明帽就是 **C 端胞外域（CED, 2210–2457）**。
- CED 晶体结构：与线虫 Piezo 同区高度相似（181 个 Cα 的 **RMSD 1.7 Å**）；CED 自身成三聚体，拟合进电镜图的**相关系数 0.89**（同时确定了手性）。
- **活细胞标记**：Flag 插在 CED 环内 → **能被表面抗体标记**；Flag 放在 C 端 → **不能**。
- 结论：**叶片与帽在胞外，梁与 C 端在胞内**。

### ④ 跨膜区怎么排？→ **每亚基 14 段，三翼 + 中央核**
- 每亚基可分辨 **14 个跨膜段** → 支持"**约 18 次跨膜**"的拓扑模型，**不支持 38 次**的旧预测。
- 命名与分工：

| 结构                 | 含义                 | 位置/作用                                               |
| ------------------ | ------------------ | --------------------------------------------------- |
| **PH1–PH12**（外周螺旋） | 每亚基 12 条，组成 6 对螺旋束 | 从中心向外周延伸，**连着胞外叶片**                                 |
| **OH**（外螺旋）        | 经 4 段 α 螺旋连到 PH1   | 包在 IH 外侧                                            |
| **anchor（锚）**      | OH→PH1 之间的发夹结构     | 穿入膜内小叶，长 α4 大致**平行于膜面**；**通过"螺旋交换"把相邻亚基扣在一起**，稳定三聚体 |
| **IH**（内螺旋）        | C 端方向最后一个跨膜段       | 位于最内层，围成中央孔                                         |
| **CTD**（C 端结构域）    | 胞内                 | 位于胞内正中央                                             |

- **anchor 的临床意义**：该区约在 **2100–2190**，含 Piezo 家族**最保守的基序 PF(X₂)E(X₆)W（2129–2140）**；致病突变 **T2142**（人 T2127）与影响孔道性质的 **E2133** 都落在这里。
- 尚未确定：PH4–PH5 之间的连接、以及三条 IH 各自归属哪个亚基。

### ⑤ 孔道在哪？→ **中央三条 IH + CTD 构成"孔道模块"**
- 膜内中心是**六条跨膜螺旋的三角形排布**：三条 **IH 在最内**（围成中央孔），三条 **OH 包在外**。
- 连同 CED 与 CTD，构成**孔道模块**，对应序列约 **2172–2547**（与此前功能研究"1974 至 C 端决定离子通透性"一致）。
- **HOLE 分析**显示一条沿轴向的连续通道，分三段前庭：**胞外（帽内）→ 跨膜（IH 围成）→ 胞内（CTD 形成）**。
- 可见明显"缩窄点"，可能是门控位置；但 **4.8 Å 看不到侧链**，无法精确测孔径。
- 这种"三聚体 + 中央孔"的组织方式让人想到 **P2X4 受体**与 **酸敏感离子通道（ASIC）**（但后两者每亚基只有 2 个跨膜段）。

### ⑥ 力从哪里来？→ **柔性叶片＋梁＝候选力传感器**
- 电镜图上**叶片远端密度"拖影"、碎片化**，而帽、跨膜骨架、梁、CTD 都清晰 → **叶片高度柔性**。
- 对称自由的三维分类得到 4 类构象：最明显的差异是**相邻叶片之间的夹角在 100°–140° 变化**（完美 C3 应为 120°），此外还有叶片相对膜面的倾斜与表面曲率变化。
- 单独精修亚区能改善帽的密度、**却改善不了叶片** → 叶片柔性正是限制整体分辨率的瓶颈。
- **提出的门控模型**：外力 → 叶片/外周螺旋运动 → 经**梁与 anchor** 传至中央 → 打开孔道。（作者强调这是**可检验的假设**，未做功能验证。）

## 一句话记住的对应关系

| 结构部件             | 推测功能                |
| ---------------- | ------------------- |
| 三个叶片（胞外、柔性）      | **感受力**（力传感器）       |
| 三根梁（胞内，80 Å）     | **传力**（把外周信号送到中心）   |
| anchor（膜内，含保守基序） | **装配与稳定**三聚体，可能参与传力 |
| 中央 IH + CTD      | **离子孔道**（门控所在）      |
| CED 帽（胞外）        | 覆盖孔道外口，形成胞外前庭       |

## 关键数字速查
- 分辨率 **4.8 Å**；蛋白 **2547 aa**；三聚体 **876 kDa**
- 直径 **200 Å**、高 **155 Å**；帽与跨膜核间距 **8 Å**；梁长 **80 Å**
- 每亚基可分辨 **14 个跨膜段**；建模覆盖 **719 个残基/亚基**
- CED 与线虫同区 **RMSD 1.7 Å**；拟合相关系数 **0.89**
- 叶片夹角摆动 **100°–140°**

## 局限
1. **4.8 Å 属中等分辨率**：无侧链，孔道半径与门控残基都只能推断。
2. **部分走向不确定**：PH4–PH5 连接缺失，三条 IH 无法逐一归属亚基。
3. **寡聚态**：不能排除膜上或其他条件存在其他形式（样品为去垢剂中纯化）。
4. **门控模型未验证**：未做孔道突变、膜张力等功能实验，叶片运动与开孔之间的因果链尚未建立。
5. 叶片柔性既是技术限制，也可能反映该区本身存在多种构象。
