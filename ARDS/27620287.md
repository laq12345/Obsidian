# Ventilator-related causes of lung injury: the mechanical power

> **论文**：Gattinoni L, Tonetti T, Cressoni M, Cadringher P, Herrmann P, Moerer O, Protti A, Gotti M, Chiurazzi C, Carlesso E, Chiumello D, Quintel M. *Intensive Care Med*. 2016;42(10):1567-1575.

## 一句话总结
论文把 VILI 的各项"呼吸机相关原因"——潮气量、驱动压、流速、呼吸频率、PEEP——统一为一个物理量：**机械功率（mechanical power，单位时间输送给呼吸系统的能量）**。作者由运动方程推导出可在床旁直接计算的公式，并用 80 例患者的压力–容积环实测能量验证（R² > 0.96），进而量化各参数对致伤能量的相对贡献。

## 研究背景与假设
- VILI 取决于两个因素：呼吸机输送了什么，以及肺如何承受。既往研究把压力、容积、流速、呼吸频率、PEEP 分开讨论，但这些其实都是同一能量负荷的不同组分。
- **假设**：呼吸机相关致伤因素可由单一变量（机械功率）概括；该功率可从潮气量（ΔV 或 TV）、驱动压（ΔP_aw）、吸气流速、PEEP、呼吸频率（RR）与吸呼比（I:E）计算；计算值与压力–容积环实测值一致，从而能评估各变量的相对贡献。

## 方法
**公式推导**：起点为运动方程

$$P = E_{Lrs}\cdot \Delta V + R_{aw}\cdot F + \text{PEEP}$$

各项乘以容积变化与呼吸频率，得到每呼吸能量三组分（对应 Fig. 1 的几何面积）：

| 组分   | 每呼吸能量                     | 图形含义                   |
| ---- | ------------------------- | ---------------------- |
| 弹性   | ½ · ΔV² · E_Lrs           | 三角形面积，即 ½ · TV · ΔP_aw |
| 阻力   | ΔV · R_aw · (ΔV / T_insp) | 平行四边形（气体运动）            |
| PEEP | ΔV · PEEP                 | 抬高基线张力，与容积变化相乘         |

将 T_insp 用 RR 与 I:E 表示，得机械功率（L·cmH₂O × 0.098 = J）：

$$\text{Power}_{rs} = 0.098\cdot RR\cdot\left[\Delta V^2\cdot\tfrac{1}{2}E_{Lrs} + RR\cdot\tfrac{1+I{:}E}{60\cdot I{:}E}\cdot R_{aw}\cdot\Delta V + \Delta V\cdot \text{PEEP}\right]$$

**验证**：30 例非肺源性机械通气患者（"正常肺"，19 外科 + 11 内科）与 50 例 ARDS 患者（轻 26 / 中 16 / 重 8）。每位患者在 PEEP 5 与 15 cmH₂O × 潮气量 6/8/10/12 ml/kg 的全部组合下通气（正常肺每 PEEP 120 次测量，ARDS 每 PEEP 200 次），以吸气支动态 P–V 环下面积作为实测每呼吸能量，乘 RR 得实测功率，与公式计算值比较。统计用单变量回归与 Bland–Altman 分析。

## 主要结果

**1. 计算值与实测值高度一致**
- 回归斜率：正常肺 0.96（PEEP 5）/ 1.06（PEEP 15）；ARDS 1.01 / 1.12；R² 均 > 0.96，P < 0.0001。
- Bland–Altman：偏差很小（均值差 −0.40 至 0.32 J/min）；15 cmH₂O PEEP 下出现**系统性高估**，原因是公式假设气道阻力恒定，而实际阻力随肺容积增加而下降。
- 举例：P_peak 32.8、P_plat 29.2 cmH₂O、TV 303 ml、RR 18 时，实测 13.9 J/min，计算 14.4 J/min。

**2. 各参数对机械功率的影响（Fig. 4，其它参数固定，逐个增加 10%）**

| 参数               | 与功率的关系         | +20% 时的功率变化 |
| ---------------- | -------------- | ----------- |
| 潮气量 / 驱动压 / 吸气流速 | 指数 ≈ 2（三者完全重合） | +37%        |
| 呼吸频率             | 指数 ≈ 1.4       | +27%        |
| PEEP             | 线性             | +5.7%       |

增倍潮气量（6→12 ml/kg）即使功率增至 **4 倍**。力学参数方面（Fig. 5）：呼吸系统弹性 E_Lrs 增加 20% → 功率 +8%；气道阻力 R_aw 增加 20% → 功率 +6%。

## 结论与临床意义
1. **容积/驱动压是首要致伤因素**：指数为 2，与"小潮气量通气"的临床证据方向一致。
2. **呼吸频率长期被忽视但影响显著**：功率随 RR 以 1.4 次幂增长，频率过高会明显增加致伤能量。
3. **PEEP 具有双重性**：一方面线性增加输送功率；另一方面可减轻肺内不均一性与周期性塌陷–复张。净效应取决于两者孰强、发生于何种患者。
4. **可床旁实现**：公式仅需呼吸机现有参数，易于写入呼吸机软件实时显示，并可预测参数调整对致伤能量的影响。
5. **功率需按肺容积标化**：健康猪的 VILI 阈值约 **12 J/min**（≈40 mJ/min/ml 肺）；"婴儿肺"容积越小，致伤所需绝对功率越低，故单纯比较 J/min 数值意义有限。
6. **功率只是一半问题**：另一半是肺本身状态（容积、不均一性、应力集中点），同样的功率在不同肺中后果不同。

## 局限（作者自述）
1. 假设 P–V 关系、阻力与流速恒定；高容积（15 cmH₂O PEEP）时出现高估。
2. 变量分析为"逐个改变、其余固定"，而临床参数常联动变化（作者提供在线计算器供任意组合估算）。
3. 输送能量中真正可能致伤的只是滞后（hysteresis）部分，但其占输送能量的比例近似恒定，故以总能量近似。
4. 能量计算基于气道压 × 容积（含胸壁），未区分肺与胸壁。
5. 验证样本量有限（80 例），且多为短期/术中通气；本文提出的是机制框架，未提供临床结局证据。
