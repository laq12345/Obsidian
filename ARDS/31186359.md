# Endothelial cell Piezo1 Mediates Pressure-Induced Lung Vascular Hyperpermeability via Disruption of Adherens Junctions

## 一句话总结
本文为"**毛细血管应力衰竭（capillary stress failure）**"这一经典病理现象找到了**分子机械感受器**：肺微血管压力升高时，**内皮细胞 Piezo1** 被激活 → Ca²⁺ 内流 → **calpain 蛋白酶**活化 → 黏附连接（AJ）蛋白 **VE-cadherin、β-catenin、p120-catenin 被内化并降解** → 细胞旁通路打开 → 富蛋白液体漏出、肺水肿。**内皮特异性敲除 Piezo1 或药理抑制 Piezo1/calpain 均可阻断这一系列反应**。

## 研究背景与问题
- **生理基础**：肺液体稳态依赖内皮屏障完整性；屏障破坏导致**富蛋白性肺水肿**。内皮**黏附连接（AJ）** 是细胞旁通路的主要决定者，由跨膜蛋白 **VE-cadherin** 与 **β-catenin、α-catenin、p120-catenin** 组成；AJ 破坏 → VE-cadherin 同型黏附减少 → 通透性升高。
- **病理现象**：West 等提出的肺毛细血管"**应力衰竭**"——左心衰、颅脑损伤（Cushing 反应）、高海拔等造成肺微血管压力升高时，薄至 **<1 μm**（血–气屏障毛细血管段可薄至约 0.3 μm）的肺泡–毛细血管屏障发生机械性破坏，产生高海拔性、神经源性、心源性肺水肿。
- **未知环节**：**内皮细胞如何"感知"压力升高并把机械刺激转成屏障破坏**？此前只知高压可破坏屏障，但感受与转导机制不明。
- **候选分子**：**Piezo1**（286 kDa 跨膜阳离子通道）由膜张力与膜曲率变化门控；内皮特异性敲除 Piezo1 会损害剪切力依赖的血管发育与出芽性血管生成；内皮 Piezo1 也参与扰动血流感受、炎症与动脉粥样硬化。**本文检验的假设**：Piezo1 感受肺内皮表面高压 → 通过 AJ 解体导致通透性升高。

## 方法
**遗传学工具**
- **Piezo1^iΔEC 小鼠**：内皮特异性、诱导型 Cre/loxP（tamoxifen 诱导）敲除 Piezo1；以 qPCR 与 Western blot（肺内皮裂解液）验证缺失。
- **VE-cadherin 稳定化敲入小鼠**：表达 VE-cadherin–F506 与 VE-PTP–FRB* 融合蛋白；**rapamycin** 使二者结合，从而**阻止 VE-cadherin 内化**、稳定 AJ。

**升高肺微血管压力的两种模型**
1. **升高左房压**（在体/离体灌流肺）：测**肺湿重**（水肿）、**毛细血管滤过系数 K_f,c**（对液体的通透性）、**白蛋白经血管通透性的表面积乘积 PS**（对蛋白的通透性）。
2. **TAC（横主动脉缩窄约 50%）** 小鼠模型：术后 24 h 左室收缩压与左房压升高，用于**持续性**压力升高的在体研究。

**结构与机制读出**
- **透射电镜 + 胶体金标记白蛋白**（6–9 nm 颗粒）计数"**开放的 AJ**"（即允许示踪剂通过的连接）。
- **Piezo1 激活**：**Yoda1（5 μM）**；膜片钳验证其特异性（记录 −110 mV 下的内向电流）。
- **VE-cadherin 定位**：细胞表面生物素化（区分质膜/胞质池）、免疫荧光（AJ 处聚集）、共免疫沉淀（与 p120-catenin 的结合）、降解片段检测。
- **calpain**：活性测定；抑制剂 **PD150606**（选择性、细胞可透过的非肽类 calpain 抑制剂）。
- **Piezo1 药理抑制**：**GsMTx4**（mechanotoxin-4）。

## 主要结果

### 1. Piezo1 介导压力升高引起的肺内皮通透性增加（Fig. 1）
- 升高左房压后，**Piezo1^fl/fl 对照小鼠**肺湿重增加、**K_f,c 显著升高**、**各压力水平下 PS 均显著升高**；**Piezo1^iΔEC 小鼠**这些反应均**明显减弱或阻断**。
- **电镜证据**：压力升高使对照小鼠肺毛细血管中**开放 AJ 的数量增加 8 倍**（AJ 处可见金标记白蛋白颗粒）；而 Piezo1^iΔEC 小鼠的 AJ 保持典型的选择性屏障形态。
- → Piezo1 是压力诱导细胞旁通路开放的**必需**环节。

### 2. Piezo1 激活导致 VE-cadherin 内化（Fig. 2）
- **特异性验证**：Yoda1 在 Piezo1^fl/fl 内皮引起内向阳离子电流，在 Piezo1^iΔEC 内皮中**无反应**。
- 人肺微血管内皮单层经 Yoda1 处理后：**质膜 VE-cadherin 时间依赖性减少**，**胞质池增加**（表面/胞内比值下降）→ **内化**。
- 免疫荧光：AJ 处 VE-cadherin 明显减少。
- 共沉淀：**VE-cadherin 与 p120-catenin 的结合显著减少**——p120-catenin 是调控 VE-cadherin 内化的关键蛋白。
- 同时出现 **90 kDa 的 VE-cadherin 降解片段**，与此前报道的"内吞过程中 VE-cadherin 被蛋白酶切割"一致。
- **因果性验证**：在 VE-cadherin 稳定化敲入小鼠中用 rapamycin 阻止内化后，**压力诱导的白蛋白与液体通透性升高显著减轻** → **VE-cadherin 内化是核心机制**。

### 3. 在体持续性高压模型同样依赖 Piezo1（Fig. 3）
- TAC 术后 24 h，两组的左房压与左室收缩压升高幅度**相同**（排除血流动力学差异的混淆）。
- **Piezo1^iΔEC 小鼠 TAC 后生存率提高**；Piezo1^fl/fl 小鼠出现**显著肺水肿**与**血管通透性升高**，而内皮敲除 Piezo1 **两者均被阻断**。
- **药理学平行验证**：GsMTx4 使 Piezo1^fl/fl 的 TAC 后白蛋白通透性降至与 Piezo1^iΔEC 相同的水平。
- TAC 后肺内 **VE-cadherin、β-catenin、p120-catenin 蛋白表达显著下降**，且在 24 h 内持续偏低；**Piezo1^iΔEC 与 GsMTx4 均能防止**这一丢失。
- 出现 **70 kDa 的 p120-catenin 裂解片段**，符合 calpain 介导的切割特征。

### 4. 机制：Piezo1 → calpain → AJ 蛋白降解（Fig. 4）
- TAC 后 1 h 与 24 h，Piezo1^fl/fl 小鼠肺内 **calpain 活性显著升高**；Piezo1^iΔEC 小鼠**完全阻断**该升高。
- **PD150606（calpain 抑制剂）** 降低 TAC 后的 calpain 活性，并**防止 VE-cadherin、β-catenin、p120-catenin 的降解**。
- → 通路为：**压力 → Piezo1 →（推测经 Ca²⁺ 内流）calpain 活化 → AJ 蛋白水解 → 连接解体 → 通透性升高**。

## 讨论要点
1. **把"应力衰竭"落到分子层面**：压力诱导的肺血管高通透性源于 **Piezo1 激活 → AJ 解体 → 细胞旁通路开放**，而不是单纯的机械撕裂。这为 West 的经典描述提供了机制解释。
2. **内化先于降解**：p120-catenin 从 VE-cadherin 上解离会启动 VE-cadherin 的内吞机制；而 p120-catenin 本身被 calpain 切割（70 kDa 片段）又会进一步降低 VE-cadherin 在表面的稳定性（p120 是决定 VE-cadherin 表面表达水平的"设定点"）；VE-cadherin 被内化后经蛋白酶切割（90 kDa 片段），最终转运至**溶酶体**降解。
3. **calpain 亚型**：内皮同时表达 **μ-calpain 与 m-calpain**。文献报道 m-calpain 在**近膜域与 catenin 结合域之间**切割 VE-cadherin 产生 90 kDa 片段，μ-calpain 亦可切割 VE-cadherin；本文观察到的片段提示**两种亚型可能都参与**。
4. **生理意义的思辨**：作者提出，压力诱导的 Piezo1 依赖性通透性升高可能是一种"**escape valve（安全阀）**"——通过可控的漏出释放压力，避免血–气屏障发生**灾难性**机械破裂。
5. **治疗启示**：抑制 Piezo1 信号可能用于**心源性肺水肿、高海拔性肺水肿、神经源性肺水肿**等以静水压升高为共同通路的肺水肿。

## 局限（作者自述与文本客观归纳）
1. **未排除其他机械敏感通道**：TRPV4 也参与压力升高诱导的肺水肿（其阻断剂可预防并缓解心衰所致肺水肿），但尚不清楚其作用是否通过稳定 VE-cadherin 连接实现——因此可能**存在并行或补偿通路**。
2. **未确定 calpain 亚型**（μ、m 或二者），也未在本研究中直接证明 Piezo1 → calpain 之间的**中间步骤**（Ca²⁺ 内流为推断，基于 calpain 活化的钙依赖性）。
3. 聚焦 **AJ**，未涉及**紧密连接**或内皮糖萼等其他屏障成分。
4. 主要机制数据来自**离体/体外**（灌流肺、内皮单层、Yoda1），在体部分依赖 **TAC 小鼠模型**，向人类临床情形（左心衰、高原、颅脑损伤）外推需谨慎。
5. TAC 引起的是**持续性**压力升高，而非 ARDS 典型的炎症性屏障破坏；本文并未研究炎症性肺损伤通路。

## 与本库主题的关系
- **把 Piezo1 直接接到肺血管屏障与水肿**：这是所读 Piezo 系列中**最贴近 ARDS 病理生理**的一篇——[[20813920]]（分子鉴定）→ [[26390154]]（结构）→ [[32744386]]（肺泡上皮侧、生理性牵张）→ **本文（肺内皮侧、病理性高压）**，形成"上皮 + 内皮"两侧的机制图景。
- **与 ARDS 的边界（需分清）**：本文的核心驱动因素是**静水压升高（心源性/高原/神经源性肺水肿）**，而 ARDS 的主因是**炎症性通透性增高**；两者在终末通路（VE-cadherin 内化与降解、AJ 解体）上高度重叠，故本文可作为"屏障破坏的力学通路"证据，但**不能**等同于"Piezo1 是 ARDS 的致病分子"。
- **与机械通气的关系（属推测层面）**：机械通气可升高肺微血管压力（尤其在高 PEEP、肺过度膨胀、液体负荷下），本文提示这一压力经由 Piezo1 转成通透性升高——为"通气相关肺水肿/应力衰竭"提供了一条候选分子路径，但**尚无通气模型中的直接验证**。
- **与宏观力学框架的层次**：跨肺压/驱动压/机械功率/应力放大（[[25693014]]、[[27620287]]、[[24261322]]、[[5442255]]）描述外力；本文描述内皮如何把**压力**转成**屏障失效**。
