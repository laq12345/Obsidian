# Mechanical stretch activates piezo1 in caveolae of alveolar type I cells to trigger ATP release and paracrine stimulation of surfactant secretion from alveolar type II cells

## 一句话总结
本文回答了肺生理学中一个长期悬而未决的问题：**肺泡充气时的机械牵张究竟如何转成"分泌表面活性物质"的生化信号**。作者提出并验证了一条完整的细胞间通路：**ATI 细胞（Ⅰ型肺泡上皮）小窝（caveolae）中的 Piezo1 通道感受膜张力 → Ca²⁺ 内流 → 激活 pannexin-1 半通道 → ATI 释放 ATP → ATP 经 P2Y2 受体旁分泌刺激邻近 ATII 细胞 → ATII 内 Ca²⁺ 升高 → 板层体胞吐、分泌表面活性物质**。关键证据是 CRISPR 敲除 caveolin-1 的 ATI 细胞：牵张响应阈值升高、响应比例下降、ATP 释放减少，并且无法再有效驱动 ATII 的板层体融合。

## 研究背景与问题
- **生理事实**：肺泡表面活性物质由 **ATII 细胞**经 Ca²⁺ 依赖的**板层体（lamellar body, LB）胞吐**分泌；**肺泡的机械变形/扩张是最强的分泌刺激**。
- **已有的碎片知识**：牵张 ATII 细胞可引起应变诱导的 Ca²⁺ 内流并促发 LB 胞吐；ATP 可经嘌呤受体刺激分泌；离体肺充气可在肺泡内引起 ATP 释放；ATI 细胞可通过 P2X7 受体与 pannexin 半通道释放 ATP。
- **未解之谜**：在**完整肺泡内**，机械变形在**分子层面**如何被感知？如何转成 Ca²⁺ 信号与分泌？
- **两个关键解剖/生理线索**：
  1. **ATI 细胞覆盖 >95% 的肺泡表面**，充气时其扩张幅度约为 ATII 细胞的**两倍**——ATI 天生适合当"机械感受器"，再通过旁分泌驱动 ATII；
  2. **小窝（caveolae）只存在于 ATI 细胞，不存在于 ATII 细胞**。小窝是 50–100 nm 的质膜内陷，其形成依赖 caveolin-1 与 cavin-1；膜张力升高时小窝会**展平**以缓冲张力并触发信号，已被公认为机械转导/机械保护结构。caveolin-1 敲除小鼠的肺泡腔变小、肺泡壁增厚，呈纤维化样表型。
- **假设**：ATI 细胞的小窝是肺泡内的机械感受装置，牵张 → Piezo1 激活 → ATP 释放 → 旁分泌刺激 ATII 分泌表面活性物质。

## 方法（实验体系）
**细胞模型**
- **hAELVi**：人肺泡上皮永生化细胞系，具 ATI 样特征、功能性紧密连接，气液界面下屏障稳定 → 作为"ATI 细胞"模型（hAELVi^wt）。
- **hAELVi^cav−/−**：用 **CRISPR/Cas9** 敲除 *CAV1*（两条 gRNA 分别位于 exon 1 CDS 起始与 exon 2 CDS 末端），FACS 单克隆化，经 Sanger 测序、基因分型、Western、RT-PCR 与免疫荧光验证。
- **原代大鼠 ATII 细胞**：按 Dobbs 法分离。
- **共培养**："肺泡上皮重建"——hAELVi + 原代 ATII 按 1×10⁵ : 2×10⁵ 接种，形成约 **40:60** 的混合单层。
- **精切肺片（precision-cut lung slices, 150 µm）**：用于验证原代组织中的表达定位。

**机械牵张与读出**
- 细胞接种于柔性 **PDMS 膜**，装入可置于倒置显微镜载物台的牵张装置（Cell Stretcher DCCS10），**单向纵向牵张**，可对同一批细胞连续观察。
- 牵张参数：**间歇 3 秒牵张、间隔 1 分钟**，幅度递增至最大 **75% 纵向延伸**；此时横向压缩 18%，**细胞–基底面积（CSA）增加约 35–40%**（换算表：10%→+5.6%、20%→+10.4%、30%→+15.7%、40%→+20.4%、50%→+26.0%、60%→+32.8%、70%→+39.4%）。
- **Ca²⁺ 成像**：Fura-2 AM（7.5 µM），340/380 比值，0.2 Hz 采集，单细胞水平分析；无钙外液用 10 mM EGTA 替代 CaCl₂。
- **板层体胞吐**：LysoTracker Red 标记酸性 LB 以识别 ATII 细胞 + **FM 1-43 融合实验**——FM 1-43 经融合孔进入 LB 后发出强荧光，可逐个记录单次融合事件。
- **ATP 定量**：**电化学微电极生物传感器**（25 µm Pt 电极，葡萄糖氧化酶/己糖激酶双酶层），置于细胞上方 **200 µm**；ATP 存在时葡萄糖被消耗、H₂O₂ 电流下降，电流降幅与 ATP 浓度成正比。
- **分子互作**：**分裂 GFP 互补（split-GFP biFC）** 判断 caveolin-1 与 Piezo1／pannexin-1 是否邻近；**共免疫沉淀**（cav1-GFP pull-down 与抗 pannexin-1 抗体 pull-down）判断是否直接结合。
- **药理学/基因学工具**：GsMTx4（5 µM，Piezo1 抑制）、Yoda1（10 µM，Piezo1 激活）、10panx（pannexin-1 抑制肽）、apyrase（ATP 水解）、suramin（P2Y 受体拮抗）、YM-254890（Gαq 抑制）、edelfosine（PLC 抑制）、heptanol（缝隙连接抑制）；siRNA 敲低 Piezo1（>80%）与 pannexin-1；腺病毒回补 caveolin-1。

## 主要结果

### 1. 敲除 caveolin-1 削弱牵张诱导的 Ca²⁺ 信号（Fig. 1–2）
- hAELVi^wt 表达 caveolin-1 的 α（24 kDa）与 β（21 kDa）两种异构体，敲除后两者均缺失；**caveolin-2 蛋白下降但 mRNA 不变**；caveolin-3 不表达。
- 周期性牵张在 hAELVi^wt 中引发胞内 Ca²⁺ 信号的**阈值 ≥15%**，而在 hAELVi^cav−/− 中**阈值升至 ≥25%**；在 75% 牵张时，**响应细胞比例显著降低**。
- Ca²⁺ 信号的产生**严格依赖胞外 Ca²⁺**（无钙条件下消失）→ 说明是**跨膜 Ca²⁺ 内流**，而非单纯胞内钙库释放。

### 2. 两类 Ca²⁺ 信号：内流"hump"与 ATP 依赖的"peak"（Fig. 3A）
- 每次牵张先出现一个小的 **Ca²⁺ "hump"**：**不被 apyrase 抑制**、但依赖胞外 Ca²⁺ → 代表**直接的 Ca²⁺ 内流**（力学门控通道）。
- 随后出现幅度大的 **Ca²⁺ "peak"**：**被 apyrase 抑制** → 代表**ATP 依赖的嘌呤能信号**（自分泌/旁分泌放大）。

### 3. 牵张 Ca²⁺ 信号依赖位于小窝中的 Piezo1（Fig. 3–4）
- hAELVi 细胞**高表达 Piezo1**（RNAseq 与 RT-PCR 证实），**不表达 Piezo2**；非透膜免疫荧光显示 Piezo1 位于**质膜**。
- **精切肺片**中：ABCa3⁺ 的 ATII 细胞不表达 caveolin-1，而跨越肺泡隔的 **caveolin-1⁺ ATI 细胞表达 Piezo1** → 原代组织印证。
- **敲低 Piezo1（>80%）或 GsMTx4 抑制**：hAELVi^wt 的牵张 Ca²⁺ 响应显著下降，降至与 cav−/− 相同的水平；对 cav−/− 细胞**无进一步作用**。
- **Yoda1（Piezo1 激活剂）可"拯救"** cav−/− 细胞的牵张响应至 wt 水平 → 提示**小窝是牵张依赖的 Piezo1 激活所必需**，而通道本身的激活能力并未丧失。
- **邻近但不直接结合**：split-GFP 互补实验在 caveolin-1–caveolin-1 之间、以及 **caveolin-1–Piezo1** 之间均产生质膜绿色荧光（其余单表达组合无信号）；但 **Piezo1 不与 caveolin-1-GFP 共沉淀** → 二者在质膜上**空间邻近**，但**非直接物理互作**。

### 4. Ca²⁺ 内流经 pannexin-1 半通道触发 ATP 释放（Fig. 5）
- ATP 微电极测得：ATP 释放随牵张幅度递增；**cav−/− 细胞释放显著减少**。
- 抑制或敲低 Piezo1 使 wt 细胞的 ATP 释放**降至 cav−/− 的水平**；**Yoda1 明显增强 cav−/− 细胞的释放**。
- **10panx 或 pannexin-1 敲低几乎完全阻断 wt 细胞的 ATP 释放** → **pannexin-1 半通道是主要释放途径**。
- ATP 一旦释放，会经 **P2Y 受体–Gαq–PLC** 通路**放大** ATI 自身的 Ca²⁺ 信号：pannexin-1 敲低、suramin、YM-254890、edelfosine 均可显著且近乎完全抑制 wt 的"peak"；对 cav−/− 影响很小（因其 ATP 释放本就少）。
- **pannexin-1 同样与 caveolin-1 邻近但不共沉淀**（Fig. 6）→ 作者推测小窝作为**信号平台**，把 Piezo1 与 pannexin-1 限制在近距离内，使局部 Ca²⁺ 微域足以高效激活半通道。

### 5. 共培养：ATI 的 cav1/Piezo1 驱动 ATII 分泌（Fig. 7）
- 共培养中**只有 ATI 样细胞表达 caveolin-1**，ATII–ATII 与 ATII–ATI 连接处可见 connexin-43。
- 与 wt ATI 共培养时，ATII 的 **Ca²⁺ 信号显著增加**；与 cav−/− 共培养时该效应**显著减弱**。
- **板层体胞吐**：一次 **60% 牵张**后 5 分钟内，至少发生 1 次 LB 融合的 ATII 细胞比例，在 wt 共培养中**显著高于** ATII 单培养或与 cav−/− 共培养。
- **对照实验链（证明是旁分泌而非缝隙连接）**：
  - 无钙外液消除响应；
  - **30 µm 内没有 wt ATI 细胞**时响应显著降低 → 需要**近距离**；
  - apyrase、suramin、10Panx、pannexin-1 siRNA、GsMTx4、Piezo1 siRNA 均显著抑制 wt 共培养条件下的响应；
  - **在 cav−/− 共培养组，只有无钙外液有效**——即 ATP/Piezo1 通路已被遗传学去除；
  - **Yoda1 处理与 caveolin-1 腺病毒回补**几乎恢复 wt 共培养时的响应水平；
  - **缝隙连接被排除**：Calcein AM 染料转移阴性，heptanol 不影响牵张后的旁分泌刺激（这与既往"ATI→ATII 经缝隙连接传递 Ca²⁺"的报道不同）。

## 讨论与提出模型（Fig. 8）
1. **通路模型**：肺泡牵张 → ATI 小窝展平/膜张力变化 → **Piezo1 开放、Ca²⁺ 内流** → 激活 **pannexin-1** → **ATP 释放** → 作用于 ATI 自身（自分泌放大）与邻近 **ATII 的 P2Y2 受体** → ATII 内 Ca²⁺ 升高 → **板层体胞吐、表面活性物质分泌**。
2. **为什么是 ATI 当感受器**：ATI 覆盖 >95% 肺泡表面、充气时扩张幅度约为 ATII 的 2 倍；而小窝只存在于 ATI。这构成一种**按需分级**的调控：较小牵张即可由 ATI 通路驱动分泌；更大应力时才直接激活 ATII 自身的应变诱导 Ca²⁺ 内流。
3. **小窝如何"激活"Piezo1**：作者提出膜曲率变化（小窝展平）改变局部膜张力，从而门控位于小窝内的 Piezo1；这与"Piezo1 可由膜张力直接门控"的既有证据一致。
4. **ATP 的空间-时间协调**：静息 BAL 液中 ATP 浓度仅低 nM 级，远低于 P2Y2 的 EC₅₀；而细胞外 ATP 会被快速水解 → 因此**释放与受体的空间邻近**至关重要，这与"旁分泌只在 30 µm 内有效"的观察吻合。
5. **疾病外推（作者推测）**：caveolin-1 缺失小鼠的纤维化样肺表型，部分可能源于**表面活性物质分泌的机械调控受损**；人类 CAV1 突变（缺乏小窝）者亦可能有类似机制。作者强调这属于推测。

## 局限（作者自述）
1. **体外模型不能完整再现体内**：牵张方案（单向、间歇 3 秒、间隔 1 分钟、最大 75%）是"生理性"与"技术可行性"的折中；体内肺泡变形是**异质**的，且 ATI 与 ATII 承受的牵张不同，因此**ATII 自身应变诱导的 Ca²⁺ 内流贡献可能被高估，而 ATI 旁分泌作用的比重可能更大**。
2. **未评估 ATII 的 ATP 释放**：作者承认近来有研究认为 ATII 是机械牵张肺中 ATP 的主要来源；两种来源**并不互斥**，只是敏感性不同（依赖 caveolin-1）。
3. 无法完全排除**膜微破裂**导致的 ATP 释放，但作者以"Fura-2 丢失仅在 <2% 细胞中出现"作为反驳证据。
4. **共沉淀阴性 ≠ 无瞬时互作**：不能排除牵张后 caveolin-1 与 pannexin-1 短暂结合。
5. 钙激活 pannexin-1 是**直接还是间接**仍未定（文献本身有争议）；本文亦未确定具体分子环节。
6. **无法做体内基因敲除验证**：作者指出敲除 caveolin-1、Piezo1 或 panx-1 会显著改变肺力学（cav1−/− 小鼠本身肺顺应性下降、肺泡腔变窄），难以干净地比较"牵张→分泌"这一环节。
7. 其他未被排除的通路：脂成纤维细胞来源的 leptin 旁分泌、气液界面表面张力的变化等，均可能参与体内调控。

## 与本库主题的关系
- **把分子机械转导接到肺泡力学上**：[[20813920]]（Piezo 的功能鉴定）与 [[26390154]]（Piezo1 的结构）回答"是什么、长什么样"，本文回答"**在肺里做什么**"——这是三篇中唯一直接涉及肺生理的一篇。
- **与 ARDS/VILI 的接口（需谨慎）**：本文研究对象是**正常生理条件下的牵张-分泌耦联**，不是损伤模型；它提供的是**ATI 作为机械感受器**这一细胞学基础，可用来理解：为何 ATI 在机械通气中承受最大形变、为何表面活性物质系统在损伤肺中失衡。但**不能**直接引用为"Piezo1 参与 VILI"的证据——那需要肺损伤模型中的直接实验。
- **层次对应**：宏观力学（跨肺压/驱动压/机械功率/应力放大：[[25693014]]、[[27620287]]、[[24261322]]、[[5442255]]）→ 组织与细胞形变（本文）→ 分子通道（Piezo1）。本文填的是"细胞如何感知"这一层。
