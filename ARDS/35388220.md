# 脂膜中 PIEZO1 的结构形变与曲率感受（膜穹顶假说的直接验证）

## 一句话总结
此前所有 Piezo 结构都来自**去垢剂**中的蛋白，因此"Piezo 把膜压成穹顶、膜张力使穹顶变平从而开门"始终只是**假说**。本文把小鼠 PIEZO1 **重构进脂质体**，直接解出**弯曲态（3.46 Å）** 与**变平态**两种结构：弯曲态与去垢剂结构相似并带有多达 9 个结合磷脂；变平态则出现**叶片变平、梁折弯、帽脱离并旋转**。最关键的是，作者**直接量出弯曲→变平过程中膜平面内面积扩张约 300 nm²**，据此算出**半数激活张力 ≈1.9 pN/nm**，与实测 T50（1.4 pN/nm）接近——**为"曲率/穹顶门控"提供了首个定量实验证据**。

## 要解决的问题
- PIEZO1 能对**皮牛（pN）级**的力作出反应（实测 T50 ≈ **1.4 pN/nm**）。
- 去垢剂中的结构显示它是**碗状三聚体**：中央孔 + 胞外帽 + 三个**弯曲、非平面**的叶片（38 个跨膜螺旋/亚基）+ 胞内梁。
- Guo & MacKinnon 据此提出 "**膜穹顶机制**"（[[29231809]]）：通道开放时穹顶变平，**投影面积增大**，膜张力做功稳定开放态。但该机制的三块拼图都是缺失的：① 是否在**真实脂膜**中也弯曲？② 变平是否真的发生？③ 面积变化是否足以解释实测的张力敏感性？
- **本文目标**：在脂质体中同时解出**弯曲态与变平态**，把这三块拼图补上。

## 怎么做（方法要点）

| 环节    | 关键做法                                                                                  |
| ----- | ------------------------------------------------------------------------------------- |
| 重构流程  | 脂质体增溶 → 加入纯化的 PIEZO1 → **去垢剂移除** → 梯度离心得到蛋白脂质体；系统筛选去垢剂种类、脂质组成与去垢剂去除方式                 |
| 两种朝向  | **outside-in**（多数；胞外帽朝向囊泡**内侧**，与囊泡曲率相配）；**outside-out**（少数；帽朝外，形成 **D 形**囊泡）         |
| 弯曲态数据 | 约 **78 万个** outside-in 囊泡 → 分辨率 **3.46 Å**                                            |
| 变平态数据 | 约 **35,000 张**显微图 → 约 **12 万**颗粒 → 中等分辨率（解析出 **26 个**跨膜螺旋）                            |
| 比较对象  | 去垢剂结构 PDB **5Z10**（Zhao 2018）、**6B3R**（Guo & MacKinnon）、PIEZO2 结构 **6KG7**（Wang 2019） |
| 定量计算  | 借用已发表的"力–叶片位移"线性关系 **y = 7.0x + 22**（Lin 等 2019）；用 ΔG = ΔG(λ=0) − λΔA 求张力             |

## 发现了什么（按 7 个问题组织）

### ① PIEZO1 真的会改变膜的形状吗？→ **会，而且与曲率"共形"**
- 空白脂质体表面光滑圆整；含 PIEZO1 的脂质体**不规则、扭曲**，二维平均像呈**水滴形**。
- 比较同一囊泡两侧的曲率半径（R_Piezo1 vs R_liposome）：
  - 当 **R_liposome 在 9.5–11.1 nm** 时，**R_Piezo1 ≈ R_liposome** → PIEZO1 与囊泡**曲率一致**，平均半径约 **10 nm**，此时通道几乎**不受膜张力**（与去垢剂中的"最稳定弯曲态"相当）；
  - 当 **R_liposome > 11 nm** 时，**R_Piezo1 < R_liposome** → 是 PIEZO1 **把膜拉弯**了。

### ② 通道能否被"纯膜力"压平？→ **能（outside-out/D 形囊泡）**
- 在罕见的 outside-out 朝向中，**PIEZO1 及其所在膜完全变平**，而囊泡对侧仍保持曲率 → 形成 **D 形囊泡**，且与囊泡大小无关。
- 这种"局部平、整体弯"的曲率失配会给 PIEZO1 施加**大得多的膜张力与弯曲力**——说明**仅靠脂膜本身的力就足以把 PIEZO1 从弯曲态推到完全变平态**。
- D 形囊泡数量很少，符合"这是**能量上不利**的状态"。

### ③ 弯曲态结构（3.46 Å）有什么新东西？→ **结合磷脂**
- 解析出 **22 个跨膜螺旋**，同时**把所在脂双层一起看清**（这是本工作的技术亮点）；帽位于囊泡内侧；嵌入的 PIEZO1 三聚体半径 **10 nm**、帽高 **10 nm**。
- 整体与去垢剂结构相似，**孔半径也相近** → 说明在 R≈10 nm 的囊泡中受到的膜张力极小（与去垢剂环境类似）。
- **8 个结合的磷脂（"blade lipids"，叶片脂）** 规律分布在 **THU7–THU9（TM25–TM36）的边界缝隙**；作者推测 THU1–6（远端叶片）还有更多未能解析的磷脂 → 这些磷脂可能是**稳定弯曲叶片的结构脂**。
- **1 个"pore lipid"（孔脂）** 位于 **OH（TM37）与 IH（TM38）之间形成的腔隙**：其疏水尾可能封住相邻 IH 之间的缝隙、甚至伸入跨膜孔，而亲水磷酸头正好位于**侧向离子门户的上方** → 提示它**可能直接参与门控**。

### ④ 变平态结构：哪里变了？
- 解析出 **26 个跨膜螺旋**，位于**平面脂双层**中；弯曲态具有的结构域都存在。
- **新增一个楔形域（wedge）**（AlphaFold2 预测对应残基 **1437–1468**），位于梁与 lateral plug 之后 → 说明**梁变平使楔形域变得有序**。
- 叶片在 **z 轴方向完全变平**，但俯视仍是螺旋桨式弯曲。
- **只保留了孔脂，8 个叶片脂都不见了** → 脂质会随构象变化重新适配。

### ⑤ 面积到底扩大了多大？→ **约 300 nm²**

| 量 | 数值 |
|---|---|
| 弯曲"纳米碗"深度 | **10 nm**（正好等于 10 nm 半径囊泡的半径） |
| 碗的曲面面积 A_bowl | **628 nm²** |
| 碗的平面投影面积 A_proj | **314 nm²** |
| 变平态投影面积 | **615 nm²**（半径 14 nm）≈ 碗面积 |
| **弯曲 → 变平的面积扩张** | **≈ 300 nm²** |

即：储存在"碗面"上的膜在变平时**全部展开进入膜平面**。

### ⑥ 这个面积变化能解释实测敏感性吗？→ **能（1.9 vs 1.4 pN/nm）**
- 按已验证的力–位移关系（**y = 7.0x + 22**），叶片位移 **10 nm** 需力约 **92 pN**（见下方"需注意"），做功约 **570 pN·nm**（图 3c 梯形面积）。
- 平衡时 ΔG = 0 → ΔG(λ=0) = λ·ΔA = 570 pN·nm；代入 **ΔA = 300 nm²**：

$$\lambda = \frac{570\ \text{pN·nm}}{300\ \text{nm}^2} \approx 1.9\ \text{pN/nm}$$

- 与实验实测的 **T50 = 1.4 pN/nm** 相当接近 → **曲率/穹顶机制在数量级与数值上都能解释 PIEZO1 的超高机械敏感性**。
> **需注意**：原文正文写作"约 **92 nN**"，但图 3c 标注为 **92 pN**，且与"570 pN·nm 的功"自洽（梯形 (22+92)/2 × 10 ≈ 570），故应为 **92 pN**——正文单位疑为笔误。

### ⑦ 变平如何变成"开门"？→ **两条路：拉帽 + 撬梁**
**A. 帽脱离 → 打开中央跨膜孔**
- 弯曲态中，**THU8 的胞外环与帽的 α1 螺旋**通过静电作用相连（此前已知：删掉帽或交联这两处会**废除机械激活**）。
- 变平时 THU8 及其胞外环**下移并倾斜** → **帽完全脱离**；脱离的帽**顺时针旋转**，THU9、OH 与孔内衬 IH 向外移动 → **孔扩张**。
- **门残基**：上部 **L2469** + 下部 **V2476、F2480**（PIEZO2 对应 L2743、V2750、F2754）。
  - 相邻 IH 上 L2469 的主链间距：弯曲态 **13 Å → 变平态 18 Å**；V2476：**11 Å → 13 Å**；
  - 而 PIEZO2（完全闭合）为 **8 Å（L2743）与 9 Å（V2750）**。
  - 从 PIEZO2 闭合孔到变平的 PIEZO1，L2469 处**扩张约 10 Å** → **变平态可能即开放孔**；但作者明确说**不能排除它是失活态**（V2476 曾被提出是失活门）。
- **胞内缩窄颈**（M2493、P2536、E2537）在弯曲→变平中**几乎没有变化** → 结合既往功能研究，倾向于认为它**不是动态门**。

**B. 梁做杠杆 → 打开胞内 lateral plug 门**
- 变平时远端 THU4 在膜平面内**外扩约 2 nm**，叶片**整体下移**成为共平面；按 PIEZO2 结构推算，最远端叶片下移可达 **约 10 nm**。
- 胞内梁**向中心滑移约 1 nm**，使此前提出的枢轴残基 **L1342/L1345** 正好位于 **CTD 三角平面下方**；随后在 **S1341** 处**折弯**，使梁远端**下移约 3 nm**。
- 这一"**杠杆式**"运动把**大幅度的叶片构象变化**转换成**小幅度的中心变化** → 引起中央 plug、lateral plug 与楔形域的重排；变平图中**中央 plug 密度更弱、楔形域出现**，且有一个三维分类显示 **lateral plug 密度碎裂**（提示"部分拔塞"状态过于动态、在中等分辨率下无法解析）。

## 局限（作者自述与文本客观归纳）
1. **变平态为中等分辨率**，缺精确侧链密度 → **孔半径曲线属推测**，无法确定其功能状态是**开放态还是失活态**。
2. **N 端 16 个（或 12 个）跨膜螺旋在两种态中都未解析** → 远端叶片即使身在脂膜中仍高度柔性；文中对"远端叶片下移约 10 nm"的估计依赖 PIEZO2 结构与推算。
3. **outside-out（变平）囊泡极罕见** → 样品强烈偏向能量有利的弯曲态，变平态的结构统计基础较弱。
4. **定量计算依赖外部数据与理想化几何**：力–位移关系取自既往研究（y = 7x + 22），面积按等效碗形/圆盘计算；"两态平衡"与"ΔG(λ=0) = 做功"是简化假设。
5. **正文 92 nN / 图 92 pN 的单位不一致**，引用时需按 pN 理解（见上文）。
6. 未做针对"孔脂""叶片脂"的功能突变验证 → 脂质作用的推断仍是相关性。

## 意义与在 Piezo 系列中的位置
- **把假说变成定量证据**：穹顶机制从"结构推测"（[[29231809]]）升级为"**在真实脂膜中直接观察到 + 数值自洽**"。
- **同时验证了两条门控路径**：**帽脱离 → 中央孔**（胞外路线）与**梁杠杆 → lateral plug**（胞内路线），并把"巨大的叶片形变"与"局部小幅门控"之间的**放大/缩小关系**讲清楚——这正是 Piezo 能"又灵敏又只让阳离子通过"的关键。
- **方法学意义**：证明可以在**重构脂质体**中做单颗粒冷冻电镜并**同时解析膜**，为膜蛋白"构象动力学"研究提供了范式。
- **与 ARDS/VILI 的关系（需谨慎）**：本文仍**不涉及肺或 ARDS**，但它是理解"**膜张力 → 通道开放**"这一最上游环节的定量基础。肺上皮/内皮的膜张力在机械通气中会改变，理论上正是通过这类机制被感知；但**从通道门控到 VILI 仍属多级推断**（域内文献地图见 [[39664395]]）。

## 关键数字速查
- 弯曲态 **3.46 Å**（约 78 万囊泡）；变平态中等分辨率（解析 **26** 个跨膜螺旋；弯曲态 **22** 个）
- 平衡曲率半径 **≈10 nm**；碗深 **10 nm**；嵌入三聚体半径 **10 nm**、帽高 **10 nm**
- 面积：碗面 **628 nm²**、投影 **314 nm²**、变平投影 **615 nm²** → **ΔA ≈ 300 nm²**
- 计算：力 **≈92 pN**、做功 **≈570 pN·nm** → **λ ≈1.9 pN/nm**（实测 T50 **1.4 pN/nm**）
- 门残基间距：L2469 **13 → 18 Å**；V2476 **11 → 13 Å**；（PIEZO2 对照 8 与 9 Å）
- 梁：向中心滑移 **≈1 nm**，在 **S1341** 折弯，远端下移 **≈3 nm**；枢轴 **L1342/L1345**
- 结合脂：**8 个叶片脂 + 1 个孔脂**
