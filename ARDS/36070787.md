# Acute respiratory distress syndrome: causes, pathophysiology, and phenotypes

> **论文**：Bos LDJ, Ware LB. *Lancet*. 2022;400(10358):1145-1156.
> **DOI**: [10.1016/S0140-6736(22)01485-4](https://doi.org/10.1016/S0140-6736(22)01485-4) ｜ **PMID**: [36070787](https://pubmed.ncbi.nlm.nih.gov/36070787/)
> **类型**：Lancet ARDS 系列综述（三篇中的第一篇；第三篇发表于 Lancet Respiratory Medicine）
> **相关笔记**：[[26903337]]（LUNG SAFE：10.4% 发生率来源）｜ [[30872586]]（ARDS Primer 2019）｜ [[4611290]]（VILI 实验基础）｜ [[10793162]]（ARMA 试验）

## 一句话定位
2019 年 Primer 之后、COVID 大流行之后的权威机制综述：在更新病因谱（COVID、电子烟、免疫治疗）的同时，把重点放在一条主线上——**ARDS 从"异质性综合征"走向"表型化（phenotyping）精准医学"**，并系统给出"预后富集 / 预测富集"的研究设计框架。

## 1. 病因：谱系在变化
- 发生率锚点：占 ICU 收治的 **10.4%**（引 LUNG SAFE 2016，即 [[26903337]]）。
- 按损伤途径分**直接（肺内）vs 间接（肺外）**：
  - 肺内：**肺炎（最常见）**、误吸；
  - 肺外：**非肺源性脓毒症（最常见）**、急性胰腺炎、严重创伤/休克/大量输血、TRALI 等。
- **2000 年后病因谱的关键变化**：
  - 创伤性 ARDS 减少（机械通气、晶体复苏、输血策略改进所致）；
  - **新病因**：电子烟/雾化产品相关肺损伤（EVALI，2018，主要影响年轻健康使用者）、免疫检查点抑制剂等免疫治疗药物、各类药物性 ARDS；
  - 病毒性肺炎周期性流行：SARS-CoV（2003）→ H1N1（2009）→ MERS（2012）→ **SARS-CoV-2（2019）**；结论段指出 COVID 大流行使 **ARDS 发病增加约 10 倍以上**。
- 易感性：饮酒、吸烟、空气污染；遗传变异（如触珠蛋白 Hp-2 变异，欧洲血统等位基因频率约 60%，与脓毒症相关 ARDS 风险增加相关）——但**多数变异罕见、归因风险小**；且多数研究来自高收入国家、欧洲血统人群。

## 2. 病理生理
### 2.1 病理
- 经典表现仍是**弥漫性肺泡损伤（DAD）**（中性粒细胞性肺泡炎+透明膜），但**尸检中仅约 45% 的临床 ARDS 有 DAD**；其他为双侧肺炎、弥漫性肺泡出血等。活检/尸检均只反映选择性人群，真实病理谱未知。

### 2.2 肺泡-毛细血管屏障损伤（原文 Figure 2：正常 → 轻度 → 重度）
- **上皮侧**：I 型细胞损伤 → II 型细胞损伤（表面活性物质生成减少，且被水肿液灭活）→ 细胞坏死、基底膜裸露；上皮糖萼脱落促炎；组织因子释放入肺泡 → 促凝、纤维蛋白沉积、透明膜形成。
- **内皮侧**：内皮细胞间缝隙形成、黏附分子（P-选择素/E-选择素）上调、血管生成素-2 释放；内皮糖萼脱落；血栓调节蛋白/内皮蛋白 C 受体脱落 → 促微血栓。
- 上皮与内皮损伤可互相触发（ROS 传递、细胞间通讯）。

### 2.3 生理后果（原文 Table 1）
屏障损伤 → 蛋白性水肿液入肺泡 → 通气/血流比失调与分流、表面活性物质失活、呼气末肺泡塌陷 → **低氧、顺应性下降、呼吸功增加**；微血管血栓 → **死腔增加（与死亡相关）**、肺动脉高压、急性右心功能不全；炎症介质入血 → SIRS → 多器官功能障碍（肺-肾、肺-脑交互）。

### 2.4 炎症
- **中性粒细胞**：早期迁入肺泡，释放 ROS、蛋白酶、脂质介质（前列腺素/白三烯）、**NETs**（激活 NLRP3 炎症小体 → IL-1β/IL-18）；
- **巨噬细胞**（组织驻留+募集）通过模式识别受体识别 DAMP/PAMP → 促炎表型 → 释放 IL-8 等趋化因子（中性粒细胞募集主要靠它们）；
- 淋巴细胞亚群、树突状细胞参与调控；系统性炎症常见，与肺外器官衰竭相关。

### 2.5 机械通气的致病作用（VILI）
- 认识转变被称为"革命性"：通气本身参与"肺损伤-炎症恶性循环"；
- 机制：**容积伤/气压伤**（过度膨胀、跨肺压升高；"baby lung"概念——只有小部分肺参与通气）、**肺萎陷伤（atelectrauma）**（肺泡重复开闭→剪切应力）、以及**强烈自主吸气努力**产生的负跨肺压同样可致伤；
- 系统性后果：细胞因子入血加重全身炎症；高胸内压损害心输出量。

### 2.6 消退、修复与纤维化
- 炎症消退是主动过程：中性粒细胞凋亡与清除、巨噬细胞表型转换、**Treg 协调**、促消退脂质介质（lipoxins、resolvins）；
- 屏障修复：上皮再生（祖细胞）、肺泡液体转运恢复、血管生成素-2→1 平衡转换、糖萼修复；
- 纤维化：促纤维化通路在 ARDS **第 1 天即可启动**；**2000 年后 ARDS 后肺纤维化减少**（肺保护通气普及所致），但 COVID 时代因重症/长病程而再度增多。

## 3. 表型化（Phenotyping）——全文最具方法论价值的部分
### 3.1 概念框架（原文 Table 2）

| 术语 | 定义 |
|------|------|
| phenotype | 基因与环境相互作用产生的可观察特征集合 |
| subgroup | 按任意切分得到的亚组（边界患者会"跳组"） |
| **subphenotype** | **数据驱动、多维评估、可被可靠区分的亚组** |
| **endotype** | 有明确功能/病理机制、最好对靶向治疗有差异反应的亚型 |

两个用途（原文 Figure 3）：
- **预后富集（prognostic enrichment）**：选事件率高的人群 → 相对风险下降不变时绝对风险下降更大 → 提高统计效力；
- **预测富集（predictive enrichment）**：选对治疗有差异反应的人群 → 提高相对风险下降。

### 3.2 按病因的表型
直接肺损伤者上皮损伤/肺泡炎症更重（caspase-1 通路上调）；肺外病因者内皮损伤/系统性炎症更重、损伤更弥漫——可能对肺复张/高 PEEP 反应更好。

### 3.3 生物学表型（核心）
- **2014 年潜类别分析发现"高炎症型/低炎症型"两个亚型**（约 30% vs 70%，后者亦称 reactive/uninflamed）；高炎症型：IL-6/IL-8/sTNFR1 高、蛋白 C 低、休克与酸中毒多、**死亡率更高、无呼吸机天数更少**；
- **治疗反应异质性**：回顾分析显示两型对**高 PEEP、液体策略、辛伐他汀**反应不同（辛伐他汀的差异效应在瑞舒伐他汀未重现）；高 PEEP 获益仅见于高炎症型；
- **COVID-19 是"预测富集"的范例**：RECOVERY 试验中皮质醇有效、IL-6 抑制剂与 JAK-STAT 抑制剂在早期呼吸支持患者中有效——而未选择的非 COVID ARDS 抗炎治疗屡屡失败；
- **炎症至少是"二维"的**（原文 Figure 4）：系统性炎症 ≠ 肺泡炎症，两者可不一致（BAL 与血浆细胞因子水平不平行），这是未来需要厘清的方向。

### 3.4 影像学表型
- CT 肺形态分**非局灶型**（弥漫/斑片，对复张/高 PEEP 反应好）与**局灶型**（背侧-下部实变为主，对俯卧位更好）；
- 评估必须在 **PEEP 5 cmH₂O** 下进行（高 PEEP 会复张肺泡、低估实变）；胸片难以区分（需 CT 或肺超声算法）；
- **LIVE 试验**（首个 ARDS"预测富集"RCT）：按肺形态个体化通气 vs 标准治疗——总体无获益；**分类正确者死亡率降 10%，误分类者死亡率大增**；因依赖胸片导致 20% 误分类。教训：**分类准确性是亚型导向治疗的前提**。

### 3.5 生理学表型
- 按定量 CT + 生理（分流、死腔）分**可复张型 vs 不可复张型**：可复张型死腔多、顺应性低、P/F 低、死亡风险高；PEEP 5→15 时其氧合、顺应性与死腔改善更明显；
- **动态数据的重要性**：生物学亚型在 day 3 内稳定；但 COVID ARDS 中用静态数据建模未找到亚型，加入**时间维度**（死腔、机械能）的纵向 LCA 才识别出两个亚型——提示"时间依赖变化"值得纳入。

## 4. 结论与未来方向
- ARDS 病因谱广，多学科都会遇到；COVID 使其发病增加约 10 倍以上；
- 损伤与内源性修复通路同样复杂，但**大多数患者肺功能可恢复至正常或接近正常**；
- **表型化只有在"亚型驱动的治疗策略"被前瞻性 RCT 验证后才可能改善结局**；
- 当前障碍：床旁快速识别生物学亚型的能力不足 + 对"如何用亚型做预测富集"的理解不完整。

## 我的判断（与文献区分）
1. **与 Primer（2019，[[30872586]]）的分工**：Primer 是全貌教科书；本文是 3 年后的**机制深化 + 表型化路线图**，写研究设计（尤其 enrichment 策略）时本文更实用。
2. **对表型化现状要清醒**（截至 2022）：生物学亚型可重复性较好且有差异治疗反应信号，但**无一项前瞻验证成功的亚型导向治疗**；LIVE 试验是"预测富集失败但提供关键教训"的案例。把亚型当作已落地的临床工具来引用是过度解读。
3. 摘要级事实核对：ICU 占比 10.4%、DAD 约 45%、COVID 增加 10 倍以上、LIVE 10%/20% 数字均来自原文。
4. 与手头文献串成完整脉络：**LUNG SAFE（2016 流行病学）→ Primer（2019 框架）→ 本文（2022 机制与表型化）**。
