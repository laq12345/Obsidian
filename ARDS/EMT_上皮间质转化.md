# EMT（上皮–间质转化）概念卡

> **类型**：概念笔记（背景知识卡，非单篇文献总结）
> **全称**：Epithelial–Mesenchymal Transition；中文亦作"上皮–间质转化"
> **反向过程**：MET（Mesenchymal–Epithelial Transition，间质–上皮转化）
> **用途**：为阅读 ARDS／肺纤维化／VILI 相关文献提供术语与判读基础
> **主要关联文献**：[[36526145]]（Piezo1 介导机械通气加重 ARDS 相关肺纤维化，核心终点即 EMT）｜ [[39664395]]（VILI 中机械敏感离子通道系统综述）｜ [[31435009]]（髓系 PIEZO1 与炎症）

## 一句话定义
**上皮细胞失去上皮特征、获得间质特征的过程**——通俗说就是"**松绑、换装、学会移动**"：从紧密排列、不移动的"砖块型"细胞，变成松散、能迁移、能分泌胶原的"工人型"细胞。

## 拆词理解

| | **上皮（epithelial）** | **间质（mesenchymal）** |
|---|---|---|
| 位置 | 覆盖体表与腔道内壁（皮肤、气道、肺泡内壁） | 填充于器官内部、支撑结构 |
| 代表细胞 | 肺泡上皮细胞、支气管上皮细胞 | 成纤维细胞、成肌纤维细胞 |
| 细胞间连接 | 紧密相连（E-cadherin 等） | 松散、可脱离 |
| 极性 | 有明确的顶–基底极性 | 前后极性，可自由移动 |
| 内部骨架 | 角蛋白（cytokeratin） | **vimentin（波形蛋白）** |
| 主要功能 | 构成屏障、气体交换、分泌 | 迁移、收缩、产生细胞外基质 |

## 转化时具体发生什么
1. **连接解体**：E-cadherin 等黏附分子下调 → 细胞间"铆钉"被拆掉；
2. **极性改变**：顶–基底极性丧失 → 获得前后极性；
3. **骨架重建**：角蛋白下调、vimentin 上调；出现应力纤维；
4. **获得收缩与"施工"能力**：α-SMA 上调，分泌胶原、纤维连接蛋白与基质金属蛋白酶；
5. **结果**：细胞可迁移、可收缩，并改变周围基质——**修复有用，失控则纤维化**。

## 四个最常用的判读标志

| 标志 | 是什么 | EMT 时 |
|---|---|---|
| **E-cadherin**（E-钙黏蛋白） | 上皮细胞间的"粘合铆钉" | **↓** |
| **Cytokeratin-8（CK8）** | 上皮细胞的内部骨架 | **↓** |
| **Vimentin**（波形蛋白） | 间质细胞的内部骨架 | **↑** |
| **α-SMA**（α-平滑肌肌动蛋白） | 收缩蛋白、成肌纤维细胞标志 | **↑** |

> 论文中"E-cadherin 与 CK8 下降、vimentin 与 α-SMA 上升"即：**细胞正在从"砖块"转向"工人"**。

## 为什么 ARDS / 机械通气文献总提它
- ARDS 患者后期的重要死因是**肺纤维化**，而 EMT 是纤维化的核心环节之一；
- **机械通气产生的周期性牵张会促进 EMT**（[[36526145]] 的核心结论）；
- 因此"某分子促进/抑制 EMT"往往等价于在问"**它是否推动肺走向纤维化**"。

## 三种分型（Kalluri & Weinberg 分类）

| 类型 | 场景 | 意义 |
|---|---|---|
| **I 型** | 胚胎发育、原肠形成、着床 | 正常、可逆 |
| **II 型** | **损伤修复、纤维化**（ARDS／肺纤维化属此类） | 修复有用，失控致纤维化 |
| **III 型** | 肿瘤进展 | 获得侵袭与转移能力 |

## 两个必须记住的限定（避免过度解读）
1. **体内多为"部分 EMT"（partial EMT）**：细胞常呈"半砖半工"的杂合态（如同时表达 KRT8 与 VIM），保留部分上皮特征。
   → **标志物阳性 ≠ 细胞真的改变了身份**，只能说明"出现 EMT 样程序"。
2. **细胞来源存在争议**：肺纤维化中的成肌纤维细胞**主要来自驻留成纤维细胞、周细胞等**，谱系追踪研究并未证明上皮细胞是主要来源。
   → 仅凭 EMT 标志 + 组织学**不能判定细胞来源**；[[36526145]] 亦未做谱系追踪。

## 附：主路程序速查（四层结构）
```
诱导信号（TGF-β、力学牵张、缺氧、ROS、ECM 变硬、炎症因子）
        ↓
胞内转导（SMAD2/3 + 非 SMAD：ERK/p38/JNK、PI3K-AKT、RHO-ROCK、YAP/TAZ、Ca²⁺-NFAT）
        ↓
核心转录因子（SNAIL/SLUG、ZEB1/ZEB2、TWIST1/2）
        ↓
效应基因（E-cadherin↓、claudin/occludin 重排、CK↓、vimentin↑、α-SMA↑、MMP↑、胶原↑）
        ↓
表型：连接解体 → 极性改变 → 迁移/收缩 → 基质重塑
```

**三个关键记忆点**
- **TGF-β 是"主路主开关"**：TGF-β → ALK5 → SMAD2/3 + SMAD4 → 上调 SNAIL/ZEB/TWIST → 关闭 *CDH1*（E-cadherin）。
- **SNAIL 受 GSK-3β 调控**：GSK-3β 使其降解；因此 Wnt 通路抑制 GSK-3β 会**稳定 SNAIL、促 EMT**。
- **miR-200 ↔ ZEB 双负反馈**：构成双稳态开关，使细胞可"锁定"于间质态。

## 与 Piezo1／机械力研究线的接口

| 接口环节 | 机制 | 证据强度 |
|---|---|---|
| 力学 → 潜伏 TGF-β 释放 | 整合素（αvβ6/αvβ8）、蛋白酶、机械力激活 ECM 中潜伏 TGF-β | 经典、证据较强 |
| 力学 → YAP/TAZ 入核 | 细胞张力/RhoA-ROCK 使 YAP/TAZ 与 TEAD、SMAD2/3 协同 | 较强 |
| Ca²⁺ → calcineurin–NFAT / CaMKII | Piezo1 介导 Ca²⁺ 内流的下游候选 | 合理，需在本系统验证 |
| ATP → 嘌呤受体（P2X/P2Y） | ATP 作为 DAMP 放大炎症与 TGF-β 信号 | 中等 |
| ATP → 邻近细胞 Piezo1 | "机械—化学"正反馈（参见 [[32744386]]） | 中等 |

**由此可解释 [[36526145]] 的一个关键观察**：**ATP 单独不足以诱导 EMT/纤维化，需与酸吸入"第一击"叠加**——因为 ATP 更像"放大器（第二信号）"，而 TGF-β 通路的启动（损伤与炎症）才是"点火（第一信号）"。

## 若要验证 EMT 主路，建议补做的实验

| 目的 | 检测 |
|---|---|
| 证明走 SMAD 主路 | p-SMAD2/3（WB／核转位）、SIS3 抑制、TGF-β 中和抗体 |
| 证明 EMT-TF 必需 | SNAIL／ZEB1 敲低或过表达、CDH1 启动子报告基因 |
| 区分完全／部分 EMT | KRT8 与 VIM 共染、单细胞测序、CDH2 检测 |
| 证明力学接口 | 整合素 αvβ6 阻断、latent TGF-β 释放 assay、YAP/TAZ 核定位 |
| 判定细胞来源 | 谱系追踪（如 Sftpc-CreERT 报告小鼠） |
