# cut 命令

> `cut` 按**列**剪切文本：从每一行里取出指定的字节、字符或字段。
> 本机版本：GNU coreutils 9.10（/usr/bin/cut）。本文所有输出均为本机实跑结果。

## 语法

```bash
cut 选项... [文件]...
cut -d分隔符 -f列表 文件      # 最常用：按字段取列
cut -c列表 文件               # 按字符位置取
```

不写文件（或写 `-`）就读标准输入，所以可以直接接在管道后面。

**列表**就是要选的位置集合，用逗号隔开多个范围，支持 5 种写法（位置从 1 开始数）：

| 写法 | 含义 |
| --- | --- |
| `N` | 第 N 个 |
| `N-M` | 第 N 到第 M 个（含 M） |
| `N-` | 第 N 个到行尾 |
| `-M` | 第 1 个到第 M 个 |
| `1,3-5` | 逗号组合，任意混搭 |

`-b`、`-c`、`-f` 三者**必须且只能给一个**。范围超出实际长度不报错，取到的是空串。

## 常用选项

| 选项                       | 长选项                | 作用        | 默认值        |
| ------------------------ | ------------------ | --------- | ---------- |
| `-d`                     | `--delimiter=字符`   | 指定字段分隔符   | TAB；只能一个字符 |
| `-f`                     | `--fields=列表`      | 按字段（列）选取  | 无，必须显式给出   |
| `-c`                     | `--characters=列表`  | 按字符位置选取   | 无，必须显式给出   |
| `-b`                     | `--bytes=列表`       | 按字节位置选取   | 无，必须显式给出   |
| `-s`                     | `--only-delimited` | 丢弃不含分隔符的行 | 默认不丢，原样输出  |
| `--complement`           | 同名                 | 对选中集合取补集  | 默认不取反      |
| `--output-delimiter=字符串` | 同名                 | 指定输出分隔符   | 沿用输入分隔符    |

## 选项详解

### -d, --delimiter=字符

指定**字段分隔符**，配合 `-f` 使用。

- 默认值：**TAB**。处理 TSV 文件时可以完全不写 `-d`
- 取值：**只能一个字符**，给多个会报错：

```bash
$ cut -d'ab' -f1 p.csv
cut: 分隔符必须是单个字符
```

（`p.csv` 内容为 `name,age,city` / `Alice,30,Beijing` / `Bob,25,Shanghai`，下同。）

```bash
$ cut -d, -f2 p.csv
age
30
25
```

注意：`cut` 不解析转义，想显式写 TAB 要用 shell 的 `-d$'\t'`，写 `-d'\t'` 是错的（其实大可不必，默认就是 TAB）。分隔符也不必是可打印字符，`=`, `:` 都很常用。cut 不认识引号，CSV 里 `"a,b"` 这种带引号的字段会被从中间的逗号切开——要按 CSV 规则解析请用 `csvcut` 或 Python。

### -f, --fields=列表

按**字段**选取，配合 `-d` 指定的分隔符使用。

- 默认值：无（必须显式给出）；分隔符默认是 **TAB**
- 取值：逗号分隔的字段号，支持范围写法 `1,3`、`2-4`、`5-`、`-3`

```bash
$ cut -d, -f2 p.csv
age
30
25

$ cut -d, -f1,3 p.csv
name,city
Alice,Beijing
Bob,Shanghai
```

注意：**`cut` 不会重排字段顺序**，`-f2,1` 和 `-f1,2` 输出完全一样，都按升序。不含分隔符的行**默认原样输出**，要丢弃需加 `-s`。

### -c, --characters=列表

按**字符**位置选取，和分隔符无关。

- 默认值：无（必须显式给出）
- 取值：同 `-f` 的列表写法，位置从 1 开始

本机是 UTF-8 locale，`-c` 是**多字节感知**的，一个汉字算 1 个字符：

```bash
$ printf '你好世界\n' | cut -c1-2
你好

$ ls -l /etc/hostname | cut -c1-10
-rw-r--r--
```

注意：适合处理权限位、日志时间戳这类**位置固定**的内容。位置超出行长给空串，不报错。

### -b, --bytes=列表

按**字节**位置选取。

- 默认值：无（必须显式给出）
- 取值：同 `-c`

UTF-8 下一个汉字占 3 个字节，`-b` 会把它从中间切断：

```bash
$ printf '你好世界\n' | cut -b1-2 | od -An -tx1
 e4 bd 0a
```

注意：处理中文文本一律用 `-c`。`-b` 只在处理二进制数据或定长记录时才有意义，配 `-n` 可以不切断多字节字符。

### -s, --only-delimited

**丢弃不含分隔符的行**（包括空行）。

- 默认值：不开——不含分隔符的行原样输出
- 只在 `-f` 模式下有效

```bash
$ printf 'a:1:x\nplainline\nb:2:y\n' > mixed.txt
$ cut -d: -f2 mixed.txt
1
plainline
2

$ cut -d: -s -f2 mixed.txt
1
2
```

注意：清洗混着表头、注释、残行的文件时特别有用。副作用是**空行也会被一起丢掉**，需要保留空行就别加。

### --complement

对选中的集合**取补集**：输出选中之外的部分。

- 默认值：不取反
- 必须先有 `-f`/`-c`/`-b`，单独用会报「您必须指定字节、字符或字段的列表」

```bash
$ cut -d, -f2 --complement p.csv
name,city
Alice,Beijing
Bob,Shanghai
```

注意：表达「除了第 2 列都要」时不用把剩下的列数一遍。取反的是**排好序、去好重的最终集合**。

### --output-delimiter=字符串

指定**输出**分隔符，默认沿用输入分隔符。

- 默认值：输入分隔符
- 取值：**任意长度的字符串**（这点和 `-d` 不同，`-d` 只收一个字符）

```bash
$ cut -d, -f1,3 --output-delimiter=' ' p.csv
name city
Alice Beijing
Bob Shanghai
```

注意：反直觉的是 `--output-delimiter=''` 不是「不要分隔符」，而是真的输出一个 NUL 字节：

```bash
$ printf 'a:1:x\n' | cut -d: -f1,3 --output-delimiter='' | od -An -tx1
 61 00 78 0a
```

想真把两列粘起来，用 `awk` 或 `sed`。

## 使用示例

### 1. 取 /etc/passwd 的用户名和登录 shell

```bash
$ cut -d: -f1,7 /etc/passwd | head -2
root:/bin/bash
smile:/usr/bin/fish
```

`/etc/passwd` 用冒号分隔，第 1 列是用户名，第 7 列是登录 shell。

### 2. 取第 2 列到行尾

```bash
$ cut -d: -f3- /etc/passwd | head -1
0:0:root:/root:/bin/bash
```

`N-` 不关心一行到底有多少列，后面全都要时最省事。

### 3. 从命令输出里取列（先压缩空格）

```bash
$ df -h | tr -s ' ' | cut -d' ' -f1,5 | head -4
文件系统 已用%
composefs 100%
/dev/nvme0n1p3 39%
devtmpfs 0%
```

`df -h` 靠空格对齐，必须先用 `tr -s ' '` 把连续空格压成一个，否则字段间空串会打乱编号（不加 `tr` 时 `cut -d' ' -f2` 取出来全是空行）。见 [[tr命令详解]]。

### 4. 取环境变量名

```bash
$ env | cut -d= -f1 | head -2
SHELL
SESSION_MANAGER
```

`名字=值` 天生适合 `-d=`，取左半边就是变量名列表。

### 5. 取最后一个字段（cut 做不到，换工具）

```bash
$ printf 'a:1:x\nfoo:bar:baz\n' | awk -F: '{print $NF}'
x
baz
$ printf 'a:1:x\nfoo:bar:baz\n' | rev | cut -d: -f1 | rev
x
baz
```

cut 没有负数索引，`-f-1` 是「第 1 列」而不是最后一列。

## 注意事项

| 问题                      | 说明/怎么办                                                                       |
| ----------------------- | ---------------------------------------------------------------------------- |
| `-d' '` 切空格对齐的输出        | 连续空格产生空字段，取出一堆空行。先 `tr -s ' '`，或改用 `awk '{print $1, $5}'`                    |
| 取不了「最后一列」               | 没有负数索引，`-f-1` 是第 1 列。用 `awk -F: '{print $NF}'` 或 `rev \| cut -d: -f1 \| rev` |
| `-f2,1` 想重排顺序           | 不会重排，永远升序且每个只出一次。要重排用 `awk -F: '{print $2":"$1}'`                            |
| 忘了 `-s`                 | 不含分隔符的行原样混进结果。加 `-s` 丢弃，但空行也会一起丢                                             |
| 处理 Windows 的 CRLF 文件    | 最后一个字段末尾带 `\r`，字符串比较全失败。先 `sed 's/\r$//'` 清洗，见 [[sed用法]]                     |
| `-c` 和 `-f` 同时给         | 报 `cut: only one type of list may be specified`，退出码 1。`-b`/`-c`/`-f` 只能选一个   |
| `-d` 给了多个字符             | 报 `cut: 分隔符必须是单个字符`，退出码 1。TAB 用默认或 `-d$'\t'`                                 |
| `--output-delimiter=''` | 输出的是 NUL 字节（`61 00 78 0a`），不是「不要分隔符」                                         |

## 全部选项

| 选项 | 说明 |
| --- | --- |
| `-b, --bytes=列表` | 只选中指定的这些字节 |
| `-c, --characters=列表` | 只选中指定的这些字符 |
| `-d, --delimiter=分隔符` | 使用指定分隔符而不是 TAB 作为字段分隔符 |
| `-f, --fields=列表` | 只选中指定的这些字段；并打印所有不包含分隔符的行，除非同时指定了 -s |
| `-n` | 与 -b 连用：不切断多字节字符 |
| `--complement` | 对选中的字节、字符或字段的集合求补集 |
| `-s, --only-delimited` | 不打印不包含分隔符的行 |
| `--output-delimiter=字符串` | 使用指定字符串作为输出分隔符，默认使用输入分隔符 |
| `-z, --zero-terminated` | 以 NUL 空字符而非换行符作为行分隔符 |
| `--help` | 显示帮助并退出 |
| `--version` | 显示版本信息并退出 |

## 速查表

```bash
# ── 按字段选列（最常用）────────────────────────────
cut -d, -f2 x.csv                 # CSV 第 2 列
cut -d, -f1,3 x.csv               # CSV 第 1、3 列
cut -d: -f1 /etc/passwd           # 用户名
cut -d: -f1,7 /etc/passwd         # 用户名 + 登录 shell
cut -d: -f3- /etc/passwd          # 第 3 列到行尾
cut -f2 x.tsv                     # TSV：TAB 是默认分隔符，不用 -d

# ── 按字符位置选 ──────────────────────────────────
cut -c1-10 文件                   # 前 10 个字符
ls -l /etc/hostname | cut -c1-10  # 权限位

# ── 修饰选项 ──────────────────────────────────────
cut -d, -f2 --complement x.csv    # 取补集：去掉第 2 列
cut -d, -f1,3 --output-delimiter=' ' x.csv   # 输出改空格
cut -d, -s -f2 x.csv              # 丢掉不含逗号的行

# ── 管道常见组合 ──────────────────────────────────
df -h | tr -s ' ' | cut -d' ' -f1,5   # 磁盘：设备 + 使用率
env | cut -d= -f1                     # 环境变量名

# ── cut 做不到、换工具 ────────────────────────────
awk -F: '{print $NF}' 文件        # 最后一个字段
awk -F: '{print $2":"$1}' 文件    # 重排字段顺序
```
