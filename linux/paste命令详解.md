# paste 命令

> 把几个文件的行**按行号横向合并**：每个文件各取一行，用分隔符接成一行。
> 本机版本：GNU coreutils 9.10（`/usr/bin/paste`）。本文所有输出均为本机实跑结果。

## 语法

```bash
paste [选项]... [文件]...
```

默认行为是**并行合并**：同时从每个文件各读一行，按顺序用 TAB 接成一行输出。`--help` 的原文一句话说清了全部规则：

> **每一行的换行符都被替换成分隔符，除了来自最后一个文件的那一列。**

这句话解释了后面所有行为：

- 中间各列的换行符换成 TAB（或 `-d` 指定的分隔符），所以列与列能接在同一行上；
- **最后一个文件**那列的换行符原样保留，所以每行以换行结尾；
- 行数不齐时，短文件那一列是空，但长文件列的换行符**照样被换成分隔符**——这就是"尾随 TAB"的由来，不是 bug；
- 只给一个文件时，它自己就是"最后一个文件"，所以输出和原文件一模一样。

没有文件参数、或文件为 `-` 时，从标准输入读取。

## 常用选项

paste 只有 3 个选项：

| 选项 | 长选项 | 作用 | 默认值 |
| --- | --- | --- | --- |
| `-d 列表` | `--delimiters=列表` | 指定列与列之间的分隔符，列表中的字符循环取用 | TAB |
| `-s` | `--serial` | 串行模式：一次处理一个文件，把它的所有行拼成一行 | 并行合并 |
| `-z` | `--zero-terminated` | 行分隔符用 NUL 而不是换行符 | 换行符 `\n` |

## 选项详解

### -d, --delimiters=列表

指定**列与列之间**的分隔符，代替默认的 TAB。

- 默认值：**TAB**
- 取值：一个或多个字符；**多个字符时按顺序循环取用**（第 1 个分隔符用第 1 个字符，第 2 个用第 2 个字符……）
- 支持转义：`\n`（换行）、`\t`（TAB）、`\\`（字面反斜杠）、`\0`（空字符串，见下）

```bash
$ printf 'a\nb\n' > A; printf '1\n2\n' > B
$ paste -d, A B
a,1
b,2
$ printf 'a\nb\nc\n' > C
$ paste -d',:' A B C | head -1
a,1:X        # 第 1 个分隔符取 ','，第 2 个取 ':'
```

注意：**`-d '\0'` 不是 NUL 字节，意思是"空字符串"（不插任何分隔符）**。实测 `paste -d'\0' A B | head -1 | od -An -tx1` 得 `61 31 0a`（即 `a1`，中间没有 `00`），和 `-d ''` 完全等价——命令行参数是 C 字符串，真正的 NUL 传不进来。要真 NUL 得用 `-z`（管的是行分隔符）。`-d '\n'` 会让每个字段单独占一行；若文件行数不齐，末尾会多出空行（分隔符照样输出）。

### -s, --serial

**串行模式**：不再并行合并，而是一次处理一个文件，把它的**所有行拼成一行**（每个文件输出一行）。文件内部的换行符换成 TAB，行尾换行符保留。

- 默认值：**并行合并**（不开 `-s` 时多个文件按行号并排）

```bash
$ paste -s A
a	b	c	d
$ paste -s A B        # 两个文件各拼一行
a	b	c	d
1	2	3
$ printf 'x\ny\nz\n' | paste -s -d ','
x,y,z
```

最常用的组合是 `-sd,`：把一个每行一个值的列表连成一行（做 CSV 单行、拼 SQL 的 `IN (...)`、拼算式）。

注意：**`paste -sd''` 是错的写法**——`''` 被 shell 消掉，命令变成 `-sd`，于是 `-d` 把下一个参数（往往是文件名）吃成分隔符。空分隔符必须分开写：`paste -s -d ''`。

### -z, --zero-terminated

把**行分隔符**从换行符换成 NUL（`\0`），输入输出都按 NUL 分行。

- 默认值：换行符 `\n`
- 用途：配合 `find -print0`、`xargs -0` 等 NUL 安全工具，处理带空格/换行的文件名

```bash
$ printf 'f 1\nf 2\n' | paste -z - - | od -An -c
   f   1  \n   f   2  \n  \t  \0        # 行分隔符变成了 NUL，列间仍是 TAB
$ find names -type f -print0 | paste -z -d'\n' - - | tr '\0' '\n'
names/b 2.txt
names/a 1.txt
```

注意：`-z` 管的是"什么算一行结束"，`-d` 管的是"列与列之间插什么"，两者独立、可叠加：`paste -z -s f` 得到一个 NUL 结尾的单行。

## 使用示例

**1. 两个清单并排成一张表**（默认并行合并，TAB 分隔）：

```bash
$ printf 'alice\nbob\n' > names.txt; printf '90\n85\n' > scores.txt
$ paste names.txt scores.txt
alice	90
bob	85
```

**2. 列表连成一行**：

```bash
$ printf 'x\ny\nz\n' | paste -sd,
x,y,z
$ seq 1 100 | paste -sd+ | bc        # 拼出算式再计算
5050
```

**3. 长列表铺成多列**（写几个 `-` 就是几列）：

```bash
$ seq 1 8 | paste - - - -
1	2	3	4
5	6	7	8
```

**4. 无分隔符拼接**（相当于 R 的 `paste0`）：

```bash
$ paste -d '' A B
a1
b2
$ paste -s -d '' A
abcd
```

**5. NUL 安全处理文件名**：

```bash
$ find names -type f -print0 | paste -z -d'\n' - - | tr '\0' '\n'
names/b 2.txt
names/a 1.txt
```

## 注意事项

| 问题 | 说明/怎么办 |
| --- | --- |
| 行数不齐产生尾随 TAB | A 4 行、B 3 行时第 4 行输出 `d<TAB>`（`cat -A` 显示 `d^I$`）。这是核心规则决定的：分隔符个数永远是"文件数 − 1"。要清理用 `sed 's/\t$//'` |
| 只给一个文件 = 原样输出 | 它自己就是"最后一个文件"，换行符不替换。不给文件参数则透传 stdin |
| `-d '\0'` 不是 NUL | 是"空字符串"，与 `-d ''` 等价（实测输出中间无 `00`）。要真 NUL 用 `-z` |
| `paste -sd''` 会翻车 | `''` 消失变成 `-sd`，`-d` 把下一个参数吃成分隔符。必须写 `paste -s -d ''` |
| 任一文件打不开 | 退出码 1，**stdout 一个字节都没有**（不像 `cat` 会输出能读的部分）。别把空输出当"结果本来就空" |
| `-d` 列表末尾裸反斜杠 | 报错：`分隔符列表的末尾有未转义的反斜杠`。要字面反斜杠写 `-d '\\'` |
| paste 只按位置配对 | 第 3 行配第 3 行，不看内容。要按键匹配用 `join`（需先排序） |
| 关于 paste0 | Unix 里**没有** `paste0` 命令，它是 R 语言的函数。`paste -d ''` ≈ `paste0(x,y)`；`paste -s -d ''` ≈ `paste0(x, collapse="")`；`paste -sd,` ≈ `paste(x, collapse=",")` |

## 全部选项

来自 `paste --help`，一条不漏：

| 选项 | 说明 |
| --- | --- |
| `-d, --delimiters=列表` | 用列表中的字符代替 TAB 作分隔符，支持反斜杠转义；字符循环取用 |
| `-s, --serial` | 一次粘贴一个文件（串行），而不是并行；文件内每行的换行符换成 TAB |
| `-z, --zero-terminated` | 行分隔符用 NUL 而非换行符 |
| `--help` | 显示帮助并退出 |
| `--version` | 输出版本信息并退出 |

## 速查表

```bash
# 并排成表（默认并行合并）
paste A B                       # TAB 分隔
paste -d, A B                   # 逗号分隔
# 列表连成一行（-s 串行）
paste -sd, list                 # x,y,z
paste -s -d '' list             # xyz（注意分开写）
seq 1 100 | paste -sd+ | bc     # 5050
# 一个流铺成多列
seq 1 8 | paste - - - -         # 四列
# NUL 安全
find . -print0 | paste -z -d'\n' - - | tr '\0' '\n'
# 其它
seq $(wc -l < A) | paste - A    # 给行编号
paste A B | sed 's/\t$//'       # 去掉尾随 TAB
```
