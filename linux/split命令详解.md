# split 命令

> 把一个大文件切成若干个小文件，切分是无损的，`cat` 拼回来和原文件逐字节相同。
> 本机版本：GNU coreutils 9.10（`/usr/bin/split`）。本文所有输出均为本机实跑结果。

## 语法

```bash
split [选项]... [文件 [前缀]]
```

两个位置参数：**文件**是要切分的输入，**前缀**是输出文件名的前半部分。省略文件（或写 `-`）时从标准输入读取；省略前缀时默认为 `x`，输出文件名就是「前缀 + 后缀」，如 `xaa`、`xab`。

## 常用选项

| 选项 | 长选项 | 作用 | 默认值 |
| --- | --- | --- | --- |
| `-l N` | `--lines=N` | 按 N 行切一个文件 | 不加任何切分选项时为 1000 行 |
| `-b SIZE` | `--bytes=SIZE` | 按字节数切，`SIZE` 可带单位 | 无（`1K`=1024 字节，`1KB`=1000 字节） |
| `-n N` | `--number=N` | 平均切成 N 份 | 无（`-n 4` 按字节均分会切断行，`-n l/4` 不断行） |
| `-d` | `--numeric-suffixes` | 后缀用数字 `00 01 02…` | 字母后缀 `aa ab ac…` |
| `-a N` | `--suffix-length=N` | 后缀位数，决定最多能生成几个文件 | 2（字母最多 676 个；配 `-d` 只有 100 个） |
| 无 | `--additional-suffix=后缀` | 在输出文件名末尾追加固定后缀 | 无（如 `.txt`） |
| `-e` | `--elide-empty-files` | 配合 `-n` 使用，不生成空文件 | 生成空文件 |
| 无 | `--verbose` | 每创建一个输出文件就打印一行 | 不打印 |

## 选项详解

### -l, --lines=行数

按**行数**切分，每 N 行生成一个文件。

- 默认值：**1000 行**（不写任何切分选项时就是这个）
- 取值：正整数

```bash
$ seq 1 2500 > n.txt
$ split -l 1000 n.txt part_
$ wc -l part_*
 1000 part_aa
 1000 part_ab
  500 part_ac
```

注意：最后一个文件可能不足 N 行（如上面的 500）。上面把默认前缀 `x` 改成了 `part_`，后缀默认是 `aa`、`ab`、`ac`…。`split n.txt` 等价于 `split -l 1000 n.txt`。

### -b, --bytes=大小

按**字节数**切分，每 SIZE 字节生成一个文件，不关心行边界。

- 默认值：无；不带单位就是纯字节数（`-b 1000` = 1000 字节）
- 取值：整数 + 可选单位。**`1K`=1024 字节，`1KB`=1000 字节**；`KiB`=`K`，`M`/`G`/`T` 同理

```bash
$ head -c 3000 /dev/urandom > b.bin
$ split -b 1K b.bin K_       # 1K = 1024 字节
$ wc -c K_*
 1024 K_aa
 1024 K_ab
  952 K_ac

$ rm -f K_*; split -b 1KB b.bin KB_   # 1KB = 1000 字节
$ wc -c KB_*
 1000 KB_aa
 1000 KB_ab
 1000 KB_ac
```

注意：`1K` 和 `1KB` 差一个数量因子，切传输分片时通常写 `-b 100M` 这种（= 104857600 字节）；想要十进制的整数值才用 `KB`。

### -n, --number=份数

把输入**平均分成 N 份**，份数固定，每份大小由总量决定。

- 默认值：无
- 取值：`N`（按字节均分）、`l/N`（均分且不切断行）、`K/N`（只把第 K 份写到标准输出）

```bash
$ seq 1 10 > n10.txt        # 共 21 字节
$ split -n 3 n10.txt n_
$ wc -c n_*
 7 n_aa
 7 n_ab
 7 n_ac
$ od -c n_aa | tail -1
0000007
```

`od` 显示 `n_aa` 结尾是 `4`、没有换行 —— **`-n 3` 是按字节均分的，第 4 行被从中间切断**。要行完整就写 `-n l/N`：

```bash
$ seq 1 200000 > big.txt
$ split -n l/4 -d -a 2 big.txt p_
$ wc -l p_*
  55555 p_00
  52382 p_01
  46032 p_02
  46031 p_03
```

注意：`-n l/4` 只保证行不断，**不保证行数相等**（先按字节分段，再退到行边界），要严格等行就自己算好行数用 `-l`。

### -d, --numeric-suffixes

输出文件的后缀改用**数字** `00 01 02…`，代替默认的字母 `aa ab ac…`。数字后缀按文件名排序就是正确顺序，拼回/并行处理时更省心。

- 默认值：不加 `-d` 时用字母后缀
- 取值：可写 `--numeric-suffixes=初值` 指定起始编号（如从 5 开始）

```bash
$ split -l 1000 -d -a 2 n.txt part_
$ ls part_*
part_00  part_01  part_02

$ split -l 3 --numeric-suffixes=5 -a 2 n10.txt s5_
$ ls s5_*
s5_05  s5_06  s5_07  s5_08
```

注意：`-d` 后 2 位后缀只有 **100 个**编号（`00`–`99`），份数多必须加大 `-a`，否则后缀耗尽、剩余数据直接丢（见注意事项）。

### -a, --suffix-length=N

设置后缀的**位数**，直接决定最多能生成几个输出文件。

- 默认值：**2 位**。字母后缀 2 位 = 26² = 676 个文件；配 `-d` 数字后缀 2 位 = 100 个
- 取值：正整数，常用 2、3、4

```bash
$ split -l 100 -a 1 -d n.txt s_    # 1 位数字最多 10 个文件，2500 行会切 25 份
split: 输出文件的后缀耗尽
$ echo $?
1
$ ls s_* | wc -l
10
```

注意：切到上限后报错退出（退出码 1），**第 11 份之后的数据没写出来，直接丢了**。份数不确定就用 `-a 3` 或 `-a 4`，多几位没有任何代价。

### --additional-suffix=后缀

在输出文件名**末尾**追加一个固定后缀，让分片保留扩展名（如 `.txt`、`.part`）。

- 默认值：无
- 取值：任意字符串，通常带 `.`

```bash
$ split -l 1000 -d -a 2 --additional-suffix=.txt n.txt part_
$ ls part_*
part_00.txt  part_01.txt  part_02.txt
```

注意：它加在整个文件名的最后（后缀之后），和 `-a` 管的「编号位数」是两回事；文件名结构是 `前缀 + 编号后缀 + 追加后缀`。

### -e, --elide-empty-files

配合 `-n` 使用：某一份没有内容时**不生成空文件**。

- 默认值：不加 `-e` 时，空份也会生成一个 0 字节文件
- 取值：无参数

```bash
$ seq 1 5 | split -n l/8 - e_
$ wc -c e_*
 2 e_aa
 2 e_ab
 2 e_ac
 0 e_ad      # 空份，照样生成了
 2 e_ae
 0 e_af
 2 e_ag
 0 e_ah

$ rm -f e_*; seq 1 5 | split -e -n l/8 - e_
$ ls e_*
e_aa  e_ab  e_ac  e_ad  e_ae   # 3 个空文件没有生成
```

注意：只对 `-n` 模式有意义，`-l`/`-b` 模式不会产生空文件。

## 使用示例

### 1. 大日志按 1000 行切开，文件名可读

```bash
$ split -l 1000 -d -a 3 --additional-suffix=.log app.log part_
$ ls part_*
part_000.log  part_001.log  part_002.log ...
```

`-d -a 3` 得到三位数字编号，`--additional-suffix=.log` 保住扩展名，一眼能看出顺序和用途。

### 2. 大文件切成 100 MiB 一份用于传输

```bash
$ split -b 100M -d -a 3 --additional-suffix=.part big.iso chunk_
$ ls -l chunk_* | head -2
-rw-r--r-- 1 smile smile 104857600 ... chunk_000.part
-rw-r--r-- 1 smile smile 104857600 ... chunk_001.part
```

目标机上 `cat chunk_*.part > big.iso` 拼回，再用 `sha256sum` 对比两端哈希确认无损。

### 3. 平均切成 4 份做并行处理（不断行）

```bash
$ split -n l/4 -d -a 2 big.txt p_
$ printf '%s\n' p_* | xargs -P 4 -n 1 wc -l
  55555 p_00
  52382 p_01
  46032 p_02
  46031 p_03
```

用 `l/4` 而不是 `4`，每份都从行首开始，并行程序才不会读到半行。相关：[[xargs-tutorial]]。

### 4. 从管道里切，不落中间盘

```bash
$ cat app.log | split -l 1000 - tmp_
$ ls tmp_*
tmp_aa  tmp_ab  tmp_ac
```

`-` 占住「文件」的位置表示读标准输入，`tmp_` 才是前缀；少了 `-`，`tmp_` 会被当成要读的文件名而报错。

### 5. 切完拼回并验证

```bash
$ split -l 1000 -d -a 2 --additional-suffix=.txt n.txt part_
$ cat part_*.txt > rebuilt.txt
$ cmp n.txt rebuilt.txt && echo "一致"
一致
```

`cat 分片*` 按 shell 排序展开文件名，数字等宽后缀保证顺序正确；`cmp` 无输出即逐字节相同。

## 注意事项

| 问题 | 说明/怎么办 |
| --- | --- |
| 后缀耗尽，数据丢失 | `-a` 位数不够时切到上限就报 `split: 输出文件的后缀耗尽` 并以退出码 1 结束，**剩余数据不会写出**。份数不确定就用 `-a 3` 或更大 |
| 重跑不清理旧文件 | split 只写自己的输出，**不会删除**上次残留的旧分片。换了参数重切后 `cat part_*` 会把旧数据也拼进去。重切前先 `rm -f 前缀*` |
| 同名文件被静默覆盖 | 输出文件已存在时直接覆盖，不提示。前缀别和要保留的文件撞名 |
| `-l` 和 `-b` 同时给 | 报 `split: 无法以多种方式进行拆分`，退出码 1，一个文件都不会生成。切分方式只能选一种 |
| `cat x* > x_all` 第二次失败 | 输出名 `x_all` 也匹配 `x*`，第二次运行报 `cat: x_all: 输入文件是输出文件`（退出码 1）。输出文件名别落在通配符范围内 |
| `-n N` 切断了行 | `-n 4` 按字节均分，会从中间劈开一行。要不切断行写 `-n l/4` |
| `-n l/N` 行数并不相等 | 它是"按字节分段再退到行边界"，200000 行切 4 份实测 55555/52382/46032/46031。要严格等行用 `-l` 自己算 |
| 大小单位混淆 | `1K`=1024 字节、`1KB`=1000 字节。切传输分片想当然写 `1KB` 会比预期小 |

## 全部选项

| 选项 | 说明 |
| --- | --- |
| `-a, --suffix-length=N` | 生成长度为 N（默认 2）的文件名后缀 |
| `--additional-suffix=后缀` | 向文件名添加一个额外的后缀 |
| `-b, --bytes=大小` | 每个输出文件的大小为指定字节数 |
| `-C, --line-bytes=大小` | 每个输出文件包含完整的行（记录），且不超过指定字节数 |
| `-d` | 使用从 0 开始的数字后缀代替字母后缀 |
| `--numeric-suffixes[=初值]` | 类似 `-d`，但可以设定后缀的初值 |
| `-x` | 使用从 0 开始的十六进制数后缀代替字母后缀 |
| `--hex-suffixes[=初值]` | 类似 `-x`，但可以设定后缀的初值 |
| `-e, --elide-empty-files` | 和 `-n` 一起使用时，不生成空的输出文件 |
| `--filter=命令` | 将输出经管道传给 shell 命令，文件名在 `$FILE` 变量中 |
| `-l, --lines=数值` | 每个输出文件包含指定行数（默认 1000） |
| `-n, --number=块数` | 生成指定个数的输出文件，支持 `N`、`K/N`、`l/N`、`l/K/N`、`r/N`、`r/K/N` |
| `-t, --separator=SEP` | 用 SEP 代替换行符作为记录分隔符，`\0` 表示 NUL 字符 |
| `-u, --unbuffered` | 配合 `-n r/...` 立即把输入复制到输出（不缓冲） |
| `--verbose` | 在每个输出文件创建前打印一行诊断信息 |
| `--help` | 显示帮助并退出 |
| `--version` | 输出版本信息并退出 |

## 速查表

```bash
# ── 按行 ──────────────────────────────────────────────
split app.log                              # 默认 1000 行一份 → xaa xab …
split -l 500 app.log part_                 # 每 500 行 → part_aa part_ab …

# ── 按大小 ────────────────────────────────────────────
split -b 100M big.iso chunk_               # 每 100 MiB = 104857600 字节
split -b 1KB big.iso chunk_                # 每 1000 字节（1K 是 1024）

# ── 按份数 ────────────────────────────────────────────
split -n 4 big.txt part_                   # 平均 4 份，按字节切，可能断行
split -n l/4 big.txt part_                 # 平均 4 份，不断行

# ── 命名（追加到上面任意命令后）───────────────────────
-d -a 3                                    # 数字三位编号 000 001 …
--additional-suffix=.log                   # 文件名末尾加 .log

# ── 输入 ──────────────────────────────────────────────
cat app.log | split -l 1000 - part_        # 读管道，- 占住文件位置

# ── 拼回 / 校验 ───────────────────────────────────────
rm -f app.log                              # 先清掉可能残留的旧输出
cat part_* > app.log
cmp app.log rebuilt.txt                    # 无输出即逐字节一致
```
