# tr 命令

> 把标准输入里的字符按位置逐个替换、删除，或把连续重复压成一个。
> 本机版本：GNU coreutils 9.10（/usr/bin/tr）。本文所有输出均为本机实跑结果。

## 语法

```bash
tr [选项]... 字符串1 [字符串2]
```

三件事必须先弄明白：

1. **字符串1、字符串2 是「字符的集合」**，不是两个要匹配的词。tr 把它们按位置对齐，建立一对一的映射：字符串1 的第 1 个字符 → 字符串2 的第 1 个字符，依此类推。集合可以用范围（`a-z`）和字符类（`[:digit:]`）展开，见下一节。
2. **只吃 stdin，吐 stdout，不接受文件参数**。写 `tr 'a' 'b' f.txt` 直接报错（rc=1）：

   ```bash
   $ tr 'a' 'b' z.txt
   tr: 多余的操作对象 “z.txt”
   $ printf 'abc\n' | tr 'a' 'b' -
   tr: 多余的操作对象 “-”          # 连 - 也不认
   ```

   喂数据只能用 `< f.txt` 重定向或管道。因此 tr **不能原地改文件**，办法见「注意事项」。
3. **核心机制是「逐字符映射」，不是字符串替换**。`tr 'ab' 'XY'` 的意思是 a→X、b→Y，跟 `ab` 这个组合无关：

   ```bash
   $ printf 'abcabc\n' | tr 'abc' 'xyz'
   xyzxyz                          # 每个字符单独换，不是把 "abc" 换成 "xyz"
   $ printf 'abcabc\n' | tr 'abc' 'X'
   XXXXXX                          # 字符串2 短了，用最后一个字符补齐
   ```

   要替换**字符串**请用 [[sed用法]] 或 `sd`，tr 做不到。

## 集合（SET）的写法

字符串1/字符串2 里能写的序列，就这几类：

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `c1-c2` | 从 c1 到 c2 的所有字符（升序） | `a-z`、`0-9`、`A-Za-z` |
| `[:class:]` | 字符类，见下表 | `[:digit:]` |
| `\n \t \r` | 换行 / 制表符 / 回车 | `tr ',' '\n'` |
| `\\` | 反斜杠本身 | `tr '\\' '/'` |
| `\NNN` | 1–3 位八进制数指定的字符 | `\0` 即 NUL、`\101` 即 A |
| `[c*]` | 在字符串2 里把 c 重复到与字符串1 等长 | `tr 'abc' '[X*]'` → `XXX` |
| `[c*n]` | n 个 c（n 以 0 开头按八进制解释） | 见下 |

字符类常用的几个：`[:alpha:]` 字母、`[:digit:]` 数字、`[:alnum:]` 字母+数字、`[:lower:]`/`[:upper:]` 小写/大写、`[:space:]` 全部空白、`[:blank:]` 空格+TAB、`[:punct:]` 标点、`[:print:]` 可打印（含空格）、`[:cntrl:]` 控制字符。

每种写法一个真实输出：

```bash
$ printf 'Hello World\n' | tr 'a-z' 'A-Z'          # 范围
HELLO WORLD
$ printf 'Hello 123\n' | tr -d '[:digit:]'         # 字符类
Hello
$ printf 'a\tb\n' | tr '\t' '|'                    # 转义
a|b
$ printf 'a\\b\n' | tr '\\' '/'                    # \\ 反斜杠本身
a/b
$ printf 'abc\n' | tr 'abc' '[X*]'                 # [c*] 补齐
XXX
$ printf 'abcdef\n' | tr 'a-f' 'A[.*3]Z'           # [c*n]：A + 3个. + Z
A...ZZ
```

## 常用选项

| 选项 | 长选项 | 作用 | 默认值 |
| --- | --- | --- | --- |
| `-c`、`-C` | `--complement` | 用字符串1 的**补集**（两者完全等价） | 不加时按字符串1 原样处理 |
| `-d` | `--delete` | 删除字符串1 里的字符，不替换 | 不加时执行替换（需字符串2） |
| `-s` | `--squeeze-repeats` | 把**连续重复**的字符压成一个 | 不加时保留重复 |
| `-t` | `--truncate-set1` | 把字符串1 截断到与字符串2 等长 | 不加时用字符串2 末字符补齐短的部分 |

短选项可合并写、顺序无关：`-cd` = `-c -d`。四个选项之外 tr 没有别的功能选项（`--help`/`--version` 除外，见「全部选项」）。

## 选项详解

### -c, -C, --complement

取**字符串1 的补集**：把字符串1 理解成「字符串1 以外的所有字符」。`-c` 和 `-C` 在本机完全等价。

- 取值：配合字符串1 使用；与 `-d` 连用时字符串2 必须省略，与替换连用时字符串2 **只能写一个字符**（否则报错，rc=1）。

```bash
$ printf 'abc123def\n' | tr -cd '[:digit:]' | od -An -c
   1   2   3                      # 只留数字（补集里的字母全删）
$ printf 'a1b2\n' | tr -c '[:alpha:]' 'X'
aXbXX                             # 非字母 → X
$ printf 'a1\n' | tr -c '[:alpha:]' 'XY'
tr: 进行替换操作时，使用字符类的补集时，字符串2 必须将
域中的所有字符映射为同一个字符            # rc=1，无任何输出
```

注意：补集包含换行符，所以 `tr -cd '[:digit:]'` 连结尾换行也删掉了（上面 od 输出里没有 `\n`）；想保留换行要手动写进去：`tr -cd '[:digit:]\n'`。

### -d, --delete

删除**字符串1**中出现的字符，不需要字符串2。

- 取值：字符串1，可含范围与字符类；**给了 `-d` 后只能有一个字符串参数**，多给报错（除非同时用 `-s`）。

```bash
$ printf 'a1b2c3\n' | tr -d '[:digit:]'
abc
$ printf 'a1b2c3\n' | tr -d '[:digit:]\n' | od -An -c
   a   b   c                      # 换行也删了，输出没有结尾换行
$ printf 'a\n' | tr -d 'a' 'b'
tr: 多余的操作对象 “b”
指定了删除操作而未指定缩减操作时，只能给定一个字符串。   # rc=1
```

注意：换行符也是字符，`tr -d '[:digit:]'` 会连结尾的换行一起处理；想保留换行要写 `tr -d '[:digit:]\n'`。`-d` 和 `-s` 可以合用（`-ds`），先删再把剩下的压缩：

```bash
$ printf 'aabbaabb\n' | tr -ds 'a' 'b'
b
```

### -s, --squeeze-repeats

把**同一个字符的连续重复**压成一个。压的是「最后一个指定的集合」里的字符：不带替换/删除时压字符串1；有替换时，先替换、再把字符串2 里连续重复的结果压成一个。

- 取值：字符串1；与替换连用时字符串2 也要给。

```bash
$ printf 'a    b   c\n' | tr -s ' ' | cat -A
a b c$
$ printf 'a\n\n\nb\n\n' | tr -s '\n' | cat -A
a$
b$                                # 一堆空行只剩一个
$ printf 'aabbaa\n' | tr -s 'ab' 'xy'
xyx                               # 先 a→x、b→y，再把连续的压成一个
```

注意：它**不跨字符种类**，空格串和 TAB 串各压各的。想所有空白压成一个换行（切行/切词）写 `tr -s '[:space:]' '\n'`——先全换成换行，再把连续换行压成一个：

```bash
$ printf 'a  b\t\tc\n' | tr -s '[:space:]' '\n'
a
b
c
```

### -t, --truncate-set1

把**字符串1 截断**到与字符串2 等长。只在做替换时有意义：默认行为是字符串2 短了用末字符补齐，`-t` 反过来把字符串1 砍短，多出的字符不做映射。

- 取值：字符串1 + 字符串2；没有字符串2 时 `-t` 无效果。

```bash
$ printf 'abc\n' | tr 'abc' 'XY'
XYY                               # 默认：字符串2 用末字符 Y 补齐
$ printf 'abc\n' | tr -t 'abc' 'XY'
XYc                               # -t：字符串1 砍成 ab，c 不映射
```

注意：想让「多余的字符原样保留」而不是被末字符吞掉，就用 `-t`。

## 使用示例

**1. 去 Windows 换行符**（最高频，CRLF → LF）：

```bash
$ printf 'a\r\nb\r\n' | tr -d '\r' | cat -A
a$
b$
```

**2. 大小写转换**（只对 ASCII 生效）：

```bash
$ printf 'Hello World\n' | tr '[:lower:]' '[:upper:]'
HELLO WORLD
$ printf 'AbCdE\n' | tr '[:upper:][:lower:]' '[:lower:][:upper:]'
aBcDe                             # 大小写互换
```

**3. 只保留某类字符**（清洗二进制垃圾、提取数字）：

```bash
$ printf 'a\x01b\x02\nc\n' | tr -cd '[:print:]\n' | od -An -c
   a   b  \n   c  \n              # 控制字符没了，文本和换行还在
```

**4. 分隔符与换行互转**：

```bash
$ printf 'a,b,c\n' | tr ',' '\n'
a
b
c
```

**5. NUL 字节处理**（配 `find -print0`；GNU tr 没有 `-z`，用 `\0` 自己换）：

```bash
$ printf 'a\0b\0' | tr '\0' '\n'
a
b
```

**6. 切词统计词频**（`-cs`：非字母数字的整段压成一个换行）：

```bash
$ printf 'the cat the hat\n' | tr -cs '[:alnum:]' '\n' | sort | uniq -c | sort -rn
      2 the
      1 hat
      1 cat
```

## 注意事项

| 问题 | 说明/怎么办 |
| --- | --- |
| 当成字符串替换 | tr 是逐字符映射，`tr 'ab' 'XY'` 是 a→X、b→Y。替换字符串用 [[sed用法]] 或 `sd` |
| 传文件名进去 | `tr: 多余的操作对象 “f.txt”`，rc=1，连 `-` 也不认。改用 `< f.txt` 或管道 |
| `tr ... < f > f` | 文件被清零且 rc=0（shell 先截断了文件）。安全写法：`tmp=$(mktemp ./f.XXXXXX) && tr ... < f > "$tmp" && mv "$tmp" f`，或用 `sed -i` |
| 处理中文/emoji | tr 是字节级的，不报错但输出乱码：`printf '你好\n' \| tr '你' '我'` → `我奈`（`好` 的第三字节 bd 撞上 `你` 的第二字节被换掉）。用 `sed 'y/你/我/'`（实测正确输出 `我好`）、awk 或 python |
| 字符类不加引号 | 被 shell 当通配符展开：目录里有名为 `p` 的文件时 `tr [:lower:] [:upper:]` 对 `Hello` 得到 `Hpppp`。一律单引号包起来 |
| `-cd` 丢换行 | 补集里含 `\n`，`tr -cd '[:digit:]'` 会把换行也删掉、输出挤成一行。写 `tr -cd '[:digit:]\n'` |
| `-c` + 字符类 + 多字符字符串2 | 直接报错退出（rc=1），无输出。字符串2 只写一个字符：`tr -c '[:alpha:]' 'X'` |
| 字符串1 有重复字符 | 后面的覆盖前面的：`tr 'hello' 'world'` 对 `hello` 得到 `wolld`。检查字符串1 别写重复 |
| SET1 末尾裸反斜杠 | 本机 9.10 给警告不报错（rc=0）：`警告：在字符串结尾使用未转义的反斜杠是一种不可移植的做法`。别这么写 |

## 全部选项

| 选项 | 说明 |
| --- | --- |
| `-c` | 使用字符串1 的补集（use the complement of ARRAY1） |
| `-C` | 同 `-c`，完全等价 |
| `-d` | 删除字符串1 中的字符，不进行替换 |
| `-s` | 把最后指定集合中连续重复的字符压成一个 |
| `-t` | 先将字符串1 截断为和字符串2 长度相同 |
| `--help` | 显示帮助并退出 |
| `--version` | 输出版本信息并退出 |

没有其他选项；GNU tr **没有** `-z`（`tr -z ...` → `tr: 无效的选项 -- z`，rc=1）。

## 速查表

```bash
# ── 删字符（-d）─────────────────────────────
tr -d '\r'                       # 去 Windows 回车（最常用）
tr -d '\n'                       # 多行拼成一行
tr -d '[:punct:]'                # 去标点

# ── 只保留（-cd，换行要手动加回）────────────
tr -cd '[:digit:]\n'             # 只留数字 + 换行
tr -cd '[:print:]\n'             # 只留可打印字符 + 换行
tr -cs '[:alnum:]' '\n'          # 切词：非字母数字段 → 一个换行

# ── 压缩（-s）───────────────────────────────
tr -s ' '                        # 多个空格 → 一个
tr -s '\n'                       # 多个空行 → 一个
tr -s '[:space:]' '\n'           # 所有空白压成换行（切行）

# ── 替换（逐字符映射）───────────────────────
tr 'a-z' 'A-Z'                   # 小写 → 大写
tr '[:upper:][:lower:]' '[:lower:][:upper:]'   # 大小写互换
tr 'A-Za-z' 'N-ZA-Mn-za-m'       # ROT13
tr ',' '\n'                      # 逗号 → 换行
tr '\0' '\n'                     # NUL → 换行（配 find -print0）

# ── 就地改文件（tr 没有 -i）─────────────────
tmp=$(mktemp ./f.XXXXXX) && tr -d '\r' < f > "$tmp" && mv "$tmp" f

# ── 千万别这样 ──────────────────────────────
# tr 'a' 'b' f.txt               ← 不接受文件名
# tr 'a' 'b' < f > f             ← 文件被清零，无报错
# tr '你' '我'                   ← 中文乱码
# tr [:lower:] [:upper:]         ← 不加引号，被 shell 展开
```
