# 文本处理三剑客：grep / sed / awk

> 一句话分工：**grep 挑行、sed 改行、awk 拆字段做计算**。
> 三者都是"逐行读入 → 处理后输出"的流式过滤器，都支持从管道读、往管道写，所以能任意拼装。
> 另外附上 `column`（第八节）：它不处理内容，只负责把前三个的输出**排成对齐的表格**（尤其对中文）。
> 本机版本：GNU grep 3.12、GNU sed 4.9、GNU Awk (gawk) 5.3.2、column (util-linux) 2.41.5（Fedora）。**本文所有输出均为本机实跑结果**，测试数据见文末附录。

## 一、先决定用哪个

| 你想做的事                | 用谁                       | 例子                                               |
| -------------------- | ------------------------ | ------------------------------------------------ |
| 找出**哪些行**含有某内容       | `grep`                   | `grep -n 'ERROR' app.log`                        |
| 只要**匹配到的那一小段**       | `grep -o`                | `grep -oP '(?<=uid=)\d+'`                        |
| 只判断**有没有**（写脚本用）     | `grep -q`                | `grep -q root /etc/passwd && echo yes`           |
| 对**整行/整文件**做替换、删除、插入 | `sed`                    | `sed -i 's/old/new/g' file`                      |
| 按**某个模式定位到行**再改      | `sed`                    | `sed '/^#/d' config.conf`                        |
| 取**第 N 列**、算和/平均/计数  | `awk`                    | `awk -F, '{s+=$3} END{print s}' f.csv`           |
| 按某列**分组统计**          | `awk`                    | `awk '{c[$1]++} END{for(i in c) print c[i], i}'` |
| 结构化格式化输出成表格          | `awk printf`             | `awk '{printf "%-10s %6d\n", $1, $2}'`           |
| 跨行处理（把 N 行拼成 1 行）    | `sed`（`N`/`-z`）或 `paste` | `sed -z 's/\n/,/g'`                              |
| 按列取（不关心内容匹配）         | `cut`                    | `cut -d, -f1,3 f.csv`                            |
| 让输出**对齐成表格**         | `column`                 | `... \| column -t -s, -c unlimited`              |

经验法则：

- **纯查找**：`grep` 最快（见第九节实测），而且写起来最短。
- **批量改文件**：`sed -i` 最省事；但要先想清楚备份和 inode（4.6 节）。
- **涉及"列"和"算"**：直接上 `awk`，别用 `grep|cut` 拼。
- **逻辑一复杂**：awk 是唯一能写 `if/for/函数/数组` 的，其它两个硬写会很难读。

## 二、三者怎么工作

### grep：一行一行地"选"

```
输入行 ──► 匹配正则? ──是──► 输出整行
                  └──否──► 丢弃
```

grep 不懂"列"，它的世界观里文件就是一堆行。要列就得配 `cut`/`awk`。

### sed：一行一行地"改"

```
读一行 ──► 放进【模式空间】 ──► 按地址找到命令 ──► 执行 ──► 输出 ──► 读下一行
                ▲                                        │
                └────── 与【保持空间】h/H/g/G/x 交换 ◄────┘
```

- **模式空间（pattern space）**：当前正在处理的那一行，`s///`、`d`、`p` 都作用在它上面。
- **保持空间（hold space）**：一块草稿纸，用于跨行运算（反转行序、合并多行都靠它）。
- 默认**每行处理完自动输出**，所以 `sed 's/a/b/'` 不需要写 `print`；加了 `-n` 才变成"只输出我明确 `p` 的行"。

### awk：一行一行地"拆字段再算"

```
读一条记录 ──► 按 FS 切成 $1 $2 ... $NF ──► 匹配 pattern? ──► 执行 { action }
                                                            │
BEGIN{...} 在最前面跑一次          END{...} 在最后跑一次 ◄────┘
```

awk 的世界观是**记录（record）+ 字段（field）**，所以它天生适合"列"。

## 三、grep：按行查找

### 3.1 语法与选项表

```bash
grep [选项...] 模式 [文件...]
grep [选项...] -e 模式1 -e 模式2 [文件...]
命令 | grep [选项...] 模式
```

| 选项                                          | 作用                          | 备注                    |
| ------------------------------------------- | --------------------------- | --------------------- |
| `-i`                                        | 忽略大小写                       |                       |
| `-v`                                        | 反向：输出**不**匹配的行              |                       |
| `-n`                                        | 显示行号                        |                       |
| `-c`                                        | 只输出匹配行数                     | 见 3.7 的 `/dev/null` 坑 |
| `-l` / `-L`                                 | 只输出**含**匹配的文件名 / **不含**的文件名 |                       |
| `-o`                                        | 只输出匹配到的那部分                  | 常配 `-E`/`-P` 提取内容     |
| `-w`                                        | 整词匹配                        |                       |
| `-x`                                        | 整行匹配                        |                       |
| `-q`                                        | 静默，只用退出码                    | 写脚本首选                 |
| `-m N`                                      | 每个文件最多匹配 N 行后停              | 大文件取样快                |
| `-A/-B/-C N`                                | 匹配行 + 后/前/前后 N 行            | 看日志上下文                |
| `-r` / `-R`                                 | 递归目录（`-R` 会跟符号链接）           |                       |
| `--include` / `--exclude` / `--exclude-dir` | 递归时筛文件                      |                       |
| `-E`                                        | 扩展正则 ERE                    | 等价 `egrep`            |
| `-F`                                        | 固定字符串（不当正则）                 | 等价 `fgrep`，最快         |
| `-P`                                        | PCRE（`\d`、`\K`、环视）          | GNU 特有，BSD/macOS 没有   |
| `-f 文件`                                     | 从文件读多个模式，一行一个               |                       |
| `-I`                                        | 跳过二进制文件                     |                       |
| `-s`                                        | 不报"文件不存在"                   |                       |
| `--color=auto`                              | 高亮                          | 大多数发行版已默认别名           |
| `-z`                                        | 记录以 NUL 分隔                  | 配 `find -print0`      |

### 3.2 基础用法（实跑）

```bash
$ grep -n 'api' access.log
2:10.0.0.7 - - [...] "GET /api/user?id=42 HTTP/1.1" 200 812
3:10.0.0.5 - - [...] "POST /api/login HTTP/1.1" 401 233
5:10.0.0.9 - - [...] "GET /api/orders HTTP/1.1" 500 1024
8:192.168.1.20 - - [...] "GET /api/orders HTTP/1.1" 200 2048
9:10.0.0.11 - - [...] "POST /api/login HTTP/1.1" 200 456

$ grep -c '10.0.0.5' access.log
4

$ grep -v 'GET' access.log | head -3
10.0.0.5 - - [...] "POST /api/login HTTP/1.1" 401 233
10.0.0.11 - - [...] "POST /api/login HTTP/1.1" 200 456

$ grep -l 'api' *.log *.txt
access.log

$ grep -w 'port' config.conf          # 整词，不会匹配 "portable"
port = 8080
port = 5432

$ grep -x 'port = 8080' config.conf   # 整行完全相等
port = 8080

$ grep -oE '[0-9]+' access.log | head -5
10
0
0
5
20
```

> [!tip] `-o` 是"提取"而非"查找"
> 想让 grep 只吐出括号/冒号后面的内容，`-o` 配 `-P` 比 `sed -n 's/.../p'` 更直观：
> ```bash
> $ grep -oP '(?<=HTTP/1.1" )\d{3}' access.log | head -4
> 200
> 200
> 401
> 304
> ```


多个匹配块之间会打印分隔符 `--`（本机因只有单块所以没出现）。

### 3.4 递归与文件筛选

```bash
$ grep -rn 'host' . --include='*.conf'      # -n 显示行号
./config.conf:3:host = 192.168.1.10
./config.conf:8:host = 10.0.0.20

$ grep -r 'port' . --include='*.conf' --exclude-dir='node_modules'
./config.conf:port = 8080
./config.conf:port = 5432
```

排除大目录一定要写 `--exclude-dir`，否则在 `node_modules`/`.git` 里搜会很慢。日常交互式搜索建议直接用 `rg`（见 [[ripgrep使用指南]]），它是递归默认、自动跳过 `.gitignore` 的 grep。

### 3.5 正则：BRE / ERE / PCRE 三档

**这是三剑客里最容易踩坑的地方**：默认（BRE）里 `+ ? | ( ) { }` 都是普通字符，要加反斜杠才有特殊含义；换成 `-E`（ERE）后反过来，它们直接就是特殊字符。

```bash
$ echo "aaa" | sed 's/a\+/X/'     # BRE：a\+ 才是"一个或多个 a"
X
$ echo "aaa" | sed 's/a+/X/'      # BRE：a+ 被当成字面的 "a+"，不匹配
aaa
$ echo "aaa" | sed -E 's/a+/X/'   # ERE：a+ 就是特殊字符
X

$ echo "a|b" | grep 'a\|b'        # BRE：\| 是"或"
a|b
$ printf 'a|b\n' | grep -E 'a|b'  # ERE：| 直接是"或"
a|b
```

| 写法                       | BRE（默认）        | ERE（`-E` / `sed -r`） |     |
| ------------------------ | -------------- | -------------------- | --- |
| 一个或多个                    | `\+`           | `+`                  |     |
| 零个或一个                    | `\?`           | `?`                  |     |
| 或                        | `\|`           | `                    | `   |
| 分组/捕获                    | `\(...\)`      | `(...)`              |     |
| 重复次数                     | `\{3\}`        | `{3}`                |     |
| 单词边界                     | `\b`、`\<`、`\>` | 同左                   |     |
| `[]` 字符类、`.`、`*`、`^`、`$` | 直接用            | 直接用                  |     |

**PCRE（`-P`，仅 GNU grep）** 额外提供 `\d \w \s`、`\K`、环视 `(?=)`/`(?<=)`：

```bash
$ grep -oP '^\S+(?= - -)' access.log | head -3      # 行首 IP：前瞻
10.0.0.5
10.0.0.7
10.0.0.5

$ grep -oP '^\S+ - - \K.*?(?= ")' access.log | head -2   # \K = 丢弃左边已匹配的部分
[20/Sep/2026:08:01:11 +0800]
[20/Sep/2026:08:01:12 +0800]
```

> [!warning] `-P` 不是可移植的
> macOS/BSD 的 grep 没有 `-P`（要 `brew install grep` 装 GNU 版并用 `ggrep`）。写脚本给别人用时，优先 `-E`；`\K`/环视这类需求用 `awk` 或 `sed -E` 改写更稳。

### 3.6 退出码与脚本用法

grep 的退出码是写 shell 判断的标准工具：

```bash
$ grep -q '500' access.log; echo exit=$?
exit=0                          # 0 = 找到了
$ grep -q 'NO_SUCH' access.log; echo exit=$?
exit=1                          # 1 = 没找到
$ grep '[' access.log; echo exit=$?
grep: 无效的正则表达式           # 2 = 出错（正则非法、文件不可读等）
exit=2
```

```bash
# 常见脚本套路
if grep -q '^PermitRootLogin yes' /etc/ssh/sshd_config 2>/dev/null; then
    echo "警告：允许 root 直接登录"
fi
```

### 3.7 grep 的坑

**① 匹配到了自己（查进程时）**

```bash
$ ps -ef | grep -c 'systemd'
21
$ ps -ef | grep -c '[s]ystemd'   # 用 [s] 让 grep 自己那行不匹配
20
```

多出来的那一行就是 `grep 'systemd'` **自己的进程**——它的命令行里含有字符串 `systemd`。改写成 `[s]ystemd` 后，grep 进程自己的命令行文本里出现的是 `[s]ystemd`（其中不含 `systemd` 这个连续子串），所以匹配不到自己，`20` 才是真实数量。

**② `>/dev/null` 会让 `-c` 走捷径（重要，本机实测）**

GNU grep 发现 stdout 是 `/dev/null` 时，认为你只关心"有没有匹配"，于是**命中第一条就退出**，不再统计。所以：

```bash
$ time grep -c 404 big.log >/dev/null        # 第 17 行就命中
0.004 s
$ time grep -c 9999999 big.log >/dev/null    # 只在最后一行命中
0.173 s
$ time grep -c 404 big.log > bench.out       # 正常输出到文件，才真的数
0.325 s
634980                                        # 真实计数
```

结论：**做性能测试、或想拿准确计数时，别把 stdout 丢给 `/dev/null`**（写文件或用 `| wc -l` 代替）。这点足以让测量结果差 80 倍。

**③ `.` 是通配符，匹配字面点要转义**

```bash
$ printf 'a.c\nabc\n' | grep 'a\.c'
a.c
$ printf 'a.c\nabc\n' | grep 'a.c'
a.c
abc
```

**④ 全有或全无：一次只匹配到"某一行"，无法跨行**

grep 无法匹配"A 后面隔两行出现 B"，那种交给 `awk '/A/{f=1} f&&/B/'`（见 5.9）；`pcre2grep -M` 也能多行匹配，但本机未安装。

## 四、sed：按行编辑

### 4.1 语法与选项

```bash
sed [选项] '地址 命令' 文件           # 单个命令
sed [选项] -e '命令1' -e '命令2' 文件  # 多个命令
sed [选项] -f script.sed 文件         # 从脚本文件读命令
命令 | sed [选项] '命令'
```

| 选项          | 作用                  | 备注                         |
| ----------- | ------------------- | -------------------------- |
| `-n`        | 不自动输出，只输出 `p` 的内容   | 提取用                        |
| `-e`        | 追加一条命令              | 等价于用 `;` 分隔                |
| `-E` / `-r` | 用扩展正则 ERE           | GNU 两者等价                   |
| `-i[后缀]`    | **原地修改文件**          | `-i.bak` 备份；BSD 要写 `-i ''` |
| `-f`        | 从文件读脚本              |                            |
| `-s`        | 多文件时**独立**计数/独立 `$` | 不加则连成一个大流                  |
| `-z`        | 记录以 NUL 分隔（整个文件当一条） | 处理含换行的文件名/整文件替换            |
| `--posix`   | 关掉 GNU 扩展           | 写可移植脚本时自测                  |

### 4.2 地址：sed 的核心

**地址决定"对哪些行执行命令"**，不写地址就是所有行。

| 地址写法                  | 含义                      | 实跑                                         |     |
| --------------------- | ----------------------- | ------------------------------------------ | --- |
| `3`                   | 第 3 行                   | `sed -n '3p'`                              |     |
| `2,5`                 | 第 2 到 5 行               | `sed -n '2,4p' users.csv` → 3 行            |     |
| `$`                   | 最后一行                    | `sed -n '$p'` → `frank,eng,18000,shenzhen` |     |
| `2,$`                 | 第 2 行到结尾                | `sed '2,$d'` 只留表头                          |     |
| `1~2`                 | 从第 1 行起，每 2 行取一个（奇数行）   | `sed -n '1~2p' users.csv`                  |     |
| `/eng/`               | 含 `eng` 的行              | 见下方"坑"                                     |     |
| `/eng/!`              | **不**含 `eng` 的行（取反）     | `sed -n '/eng/!p' users.csv`               |     |
| `/start/,/end/`       | 从匹配 start 到匹配 end 的范围   | `sed -n '/alice/,/carol/p'`                |     |
| `/start/,+2`          | 从匹配行开始 + 之后 2 行（GNU 扩展） | `sed -n '/alice/,+2p' users.csv`           |     |
| `/start/,/end/{//!p}` | 范围**不含**首尾两行（GNU 技巧）    | 见 4.9                                      |     |
| `0,/re/`              | 从文件开头到第一次匹配（GNU）        | 替换第一个匹配块                                   |     |

```bash
$ sed -n '2,4p' users.csv
alice,eng,18000,beijing
bob,ops,12000,shanghai
carol,eng,24000,beijing

$ sed -n '2p;5p' users.csv        # 分号连接多个地址+命令
alice,eng,18000,beijing
dave,hr,9000,chengdu

$ sed -n '/alice/,/carol/p' users.csv
alice,eng,18000,beijing
bob,ops,12000,shanghai
carol,eng,24000,beijing

$ sed -n '1~2p' users.csv         # 奇数行
name,dept,salary,city
bob,ops,12000,shanghai
dave,hr,9000,chengdu
frank,eng,18000,shenzhen
```

> [!warning] `/eng/` 是**子串**匹配，不是字段匹配
> ```bash
> $ sed -n '/eng/p' users.csv
> alice,eng,18000,beijing
> carol,eng,24000,beijing
> dave,hr,9000,chengdu      ← 因为 "chendu" 里也有 eng！
> frank,eng,18000,shenzhen
> ```
> 要按字段精确匹配，用 `awk -F, '$2=="eng"'`（这才是"第 2 列等于 eng"）。**这是 sed 最容易出错的地方**：它只有"行"，没有"列"。

### 4.3 命令表

| 命令 | 作用 | 例子 |
|------|------|------|
| `s/原/新/标志` | 替换 | 见 4.4 |
| `p` | 打印当前行 | 配 `-n` |
| `d` | 删除当前行 | `sed '/^$/d'` |
| `a\文本` | 在当前行**后**追加 | `sed '3a\新行'` |
| `i\文本` | 在当前行**前**插入 | `sed '1i\# 头'` |
| `c\文本` | **整行替换** | `sed '/debug/c\level = info'` |
| `y/abc/xyz/` | 逐字符转换（长度必须相等） | 小写转大写 |
| `q` | 处理完当前行就退出 | 相当于 `head -n` |
| `=` | 输出行号 | 配 `N; s/\n/\t/` |
| `n` / `N` | 读下一行（覆盖 / 追加到模式空间） | 跨行 |
| `D` / `P` | 删掉/打印模式空间**第一行**（不退出） | 循环处理 |
| `h` `H` `g` `G` `x` | 模式空间 ↔ 保持空间 复制/追加/交换 | 反转行序 |
| `b 标签` / `t 标签` / `T 标签` | 无条件/条件跳转 | 循环 |
| `r 文件` / `w 文件` | 读入文件内容 / 把当前行写入文件 | |

### 4.4 替换 `s///` 全解

格式：`s/正则/替换/标志`，**默认只替换每行第一处**。

```bash
$ echo 'goologoogle' | sed 's/o/0/'      # 不写标志：第一个
g0ologoogle
$ echo 'goologoogle' | sed 's/o/0/g'     # g：全部
g00l0g00gle
$ echo 'goologoogle' | sed 's/o/0/2'     # 只替换第 2 个
go0logoogle
$ echo 'goologoogle' | sed 's/o/0/2g'    # 从第 2 个开始全换
go0l0g00gle
$ echo 'goologoogle' | sed 's/o/0/gI'    # gI：全局 + 忽略大小写
g00l0g00gle
$ echo 'goologoogle' | sed 's/o/0/2p'    # 配 -n 时，p 只打印发生替换的行
```

| 标志 | 含义 |
|------|------|
| `g` | 全部替换（不只是第一个） |
| `N` | 只替换第 N 个匹配 |
| `N g` | 从第 N 个开始全替换 |
| `I` / `i` | 忽略大小写 |
| `p` | 替换成功则打印该行（常配 `-n` 做提取） |
| `w 文件` | 替换成功则写入文件 |

**分隔符可换成任意字符**，替换内容含 `/` 时很有用：

```bash
$ echo '/usr/local/bin/app' | sed 's|.*/||'
app
$ echo '2026/09/20' | sed 's#/#-#g'
2026-09-20
```

**反向引用 `\1 \2`、整段 `&`、大小写转换**：

```bash
$ echo 'john smith' | sed 's/\([a-z]*\) \([a-z]*\)/\2, \1/'      # BRE 要转义括号
smith, john
$ echo 'john smith' | sed -E 's/([a-z]+) ([a-z]+)/\2, \1/'        # ERE 更清爽
smith, john
$ echo '2026-09-20' | sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3\/\2\/\1/'
20/09/2026
$ echo 'hello world' | sed -E 's/.*/[&]/'          # & = 整个匹配
[hello world]
$ echo 'hello world' | sed -E 's/(\w+) (\w+)/\U\1\E-\L\2/'   # \U 大写 \L 小写 \E 结束
HELLO-world
$ echo 'hello world' | sed -E 's/\w+/\u&/g'        # \u 首字母大写
Hello World
```

| 转义 | 含义 |
|------|------|
| `&` | 整个匹配内容 |
| `\1`..`\9` | 第 N 个捕获组 |
| `\U` / `\L` / `\E` | 之后转大写 / 小写 / 结束转换 |
| `\u` / `\l` | 下一个字符转大写 / 小写 |

> [!tip] `\w` 在 GNU sed 可用但不是 POSIX
> `\w \W \b \s` 是 GNU 扩展，本机 GNU sed 4.9 支持。要严格可移植就写成 `[A-Za-z0-9_]`。

### 4.6 `-i` 原地修改：好用但危险

```bash
$ sed -i 's/old/new/g' file.txt          # 直接改
$ sed -i.bak 's/old/new/g' file.txt      # 改之前存 file.txt.bak（推荐）
$ sed -i 's/foo/bar/g' *.txt             # 批量
```

> [!danger] 三个必须知道的点
> **① `-i` 不是就地写，而是"新建文件 + 替换"**——本机实测 inode 会变：
> ```bash
> $ ls -i u.csv; sed -i 's/eng/ENG/' u.csv; ls -i u.csv
> 7304 u.csv
> 7306 u.csv        ← inode 变了
> ```
> 后果：**硬链接会被断开**、**符号链接会被替换成普通文件**。普通权限位倒是会沿用（实测 `chmod 600` 后编辑仍是 `-rw-------.`），但因为换了 inode，ACL、扩展属性（xattr）等不保证跟着走。
> ```bash
> $ ls -l link.csv                          # 本来是指向 ../users.csv 的软链
> lrwxrwxrwx. 1 smile smile 12 ... link.csv -> ../users.csv
> $ sed -i 's/eng/ENG/' link.csv
> $ ls -l link.csv
> -rw-r--r--. 1 smile smile 163 ... link.csv   ← 变成普通文件了，链接关系没了
> ```
> **② 后缀必须紧贴 `-i`**，中间加空格会被当成脚本：
> ```bash
> $ sed -i .bak 's/eng/ENG/' x.csv
> sed：-e 表达式 #1，字符 1：未知的命令：“.”
> ```
> **③ 改重要文件先用 `-i.bak`，或者先 `sed ... file | diff - file` 看一眼。**

### 4.7 多命令与代码块

```bash

$ sed 's/a/b/; s/c/d/' f                 # 分号（注意某些 BSD sed 对 ; 挑剔）
$ sed -n '2,3{s/,/ | /g; p}' users.csv   # {} 代码块：块内命令共享地址

```

### 4.8 高级：模式空间 / 保持空间 / N D P 循环

这些是"sed 能做到但很少人记得"的部分，用于跨行任务。

**① 把多行合成一行**

```bash
# 全部合并（读到最后一行才替换，避免中途分隔符问题）
$ printf 'hello\nworld\nfoo\n' | sed ':a;N;$!ba;s/\n/, /g'
hello, world, foo

# 更简单的现代写法：-z 把整个文件当成一条记录
$ printf 'a\nb\nc\n' | sed -z 's/\n/,/g'
a,b,c,
```

**② 反转行序（等效 `tac`）**

```bash
$ printf 'a\nb\nc\n' | sed '1!G;h;$!d'
c
b
a
```

**③ 删除相邻重复行（等效 `uniq`）**

```bash
$ printf 'x\nx\ny\nx\nx\nx\nz\n' | sed '$!N;/^\(.*\)\n\1$/!P;D'
x
y
x
z
```

**④ 多个连续空格压成一个（`t` 循环）**

```bash
$ cat spaces.txt

$ sed -E ':a;s/  +/ /g;ta' spaces.txt

```

**⑤ 多个连续空行压成一个**

```bash
$ printf 'a\n\n\nb\n' | sed '/^$/N;/^\n$/D'
a
                 ← 3 个空行变 1 个
b
```

**⑥ 打上行号**

```bash
$ sed '=' users.csv | sed 'N;s/\n/\t/'

2	alice,eng,18000,beijing
3	bob,ops,12000,shanghai
...
```

```bash
# 提取访问日志的 5 个字段（IP 方法 路径 状态码 字节）
$ sed -E 's/^([0-9.]+) .*"(\w+) ([^ ]+) HTTP[^"]*" ([0-9]{3}) ([0-9]+)$/\1 \2 \3 \4 \5/' access.log | head -3
```

多文件独立计数要用 `-s`：

```bash

10.0.0.5 - - [...] "GET /index.html HTTP/1.1" 200 5321
$ sed -s -n '1p' access.log users.csv       # -s：每个文件各算各的

```

### 4.10 sed 的坑

**① `.*` 是贪婪的**

```bash
$ echo '<a><b>' | sed 's/<.*>/X/'
X                        ← 一口气吃到最后一个 >
$ echo '<a><b>' | sed 's/<[^>]*>/X/'
X<b>                     ← 用 [^>]* 模拟"非贪婪"
```

**② `.` 必须转义才能匹配字面点**

```bash
$ echo 'a.b.c' | sed 's/\./_/g'
a_b_c
```

**③ `/eng/` 是子串匹配**（见 4.2 的警告）——要按"列"判断请用 awk。

**④ BRE 里 `+ ? { } ( ) |` 都要加反斜杠**（见 3.5 对照表）。

**⑤ `sed` 的 `$` 在多文件时不重置**——需要 `-s`。

**⑥ 替换串里的特殊字符**：`&` 表示整个匹配，要字面 `&` 得写 `\&`；`\` 也需成对。

```bash
$ echo 'a&b' | sed 's/&/ 和 /'
a 和 b
$ echo '100' | sed 's/0/&0/g'      # 每个 0 后面再加一个 0
1000
```

## 五、awk：按字段计算

### 5.1 语法与执行模型

```bash
awk [选项] 'pattern { action }' 文件...
awk [选项] 'BEGIN{...} pattern { action } END{...}'
命令 | awk 'pattern { action }'
```

- `pattern` 省略 = 每行都执行；`action` 省略 = 默认 `{print $0}`。
- `BEGIN{}` 在处理输入**之前**跑一次（初始化、打表头）；`END{}` 在**所有输入处理完**后跑一次（汇总）。
- 只写 `pattern`（如 `awk '$9==404'`）等价于 `awk '$9==404 {print $0}'`。
- `awk -F, '{...}'`：`-F` 指定字段分隔符；`-v name=value` 从外部传变量。

### 5.2 内置变量

| 变量 | 含义 |
|------|------|
| `$0` | 整行（整条记录） |
| `$1`…`$NF` | 第 1 到最后一个字段 |
| `NF` | 当前行的字段数（`$NF` 就是最后一列） |
| `NR` | 已读记录总数（多文件累加） |
| `FNR` | 当前文件的记录号（每个文件从 1 开始） |
| `FILENAME` | 当前文件名 |
| `FS` / `OFS` | 输入 / 输出字段分隔符（默认空格/Tab、输出空格） |
| `RS` / `ORS` | 输入 / 输出记录分隔符（默认换行） |
| `RSTART` / `RLENGTH` | `match()` 的起点和长度 |
| `ARGIND` | 当前文件参数序号（gawk） |
| `ENVIRON["VAR"]` | 读环境变量 |

```bash
$ awk '{print $NF}' access.log | head -3        # 最后一列（字节数）
5321
812
233
$ awk '{print $(NF-1)}' access.log | head -3    # 倒数第二列（状态码）
200
200
401
```

### 5.3 分隔符

```bash
$ awk -F, '{print $1, $3}' users.csv            # 逗号分隔
$ awk -F'\t' '{print $2}' file.tsv             # 制表符
$ printf 'a1b22c333d\n' | awk -F'[0-9]+' '{for(i=1;i<=NF;i++) print i, $i}'
1 a
2 b
3 c
4 d
$ printf 'a::b::c\n' | awk -F'::' '{print $2}'
b
$ printf 'a b  c\n' | awk -F'[ \t]+' '{print NF}'   # 连续空白当一个 → 3
$ printf '   x y\n' | awk '{print NF, "["$1"]"}'    # 默认 FS 自动吃掉行首空白
2 [x]
```

要点：

- **`FS` 是正则**，`-F'[0-9]+'`、`-F'[,;]'` 都合法。
- **FS 为单个空格时是特例**：默认值（也包括显式 `-F' '`）表示"按空白切分"——**连续空白折叠成一个分隔符**，行首尾空白被忽略，而且换行也算空白（段落模式时有用）。它跟正则里的空格**不是**一回事，想按"一个空格切一列"必须写成 `[ ]`：

```bash
$ printf 'a b  c\n' | awk -F' '      '{print NF}'      # 单个空格（含默认）：按空白切分
3
$ printf 'a b  c\n' | awk -F'[ ]'    '{print NF}'      # 正则 [ ]：一格一列
4
$ printf 'a b  c\n' | awk -F'[ \t]+' '{print NF}'      # 显式折叠连续空白
3
```

- 输出列用 `OFS`：

```bash
$ awk -F, 'BEGIN{OFS="|"} {print $1,$2,$4}' users.csv
name|dept|city
alice|eng|beijing
...
```

- **CSV 里有引号包裹的逗号**，用 `FPAT`（gawk）或 `gawk --csv`：

```bash
$ echo 'alice,"beijing, cn",18000' | awk -v FPAT='([^,]*)|("[^"]+")' '{print $2}'
"beijing, cn"

$ gawk --csv 'NR>1 {print $4}' users.csv      # gawk 5.3+ 内置 CSV 解析
beijing
shanghai
beijing
```

**按段落（空行分隔）读取**：

```bash
$ printf 'a\nb\n\nc\nd\n' | awk 'BEGIN{RS=""} {print "段"NR"："$1"-"$NF}'
段1：a-b
段2：c-d
```

### 5.4 过滤：条件、比较、正则

```bash
$ awk -F, 'NR>1 && $3>15000 {print $1, $3}' users.csv     # 数值比较
alice 18000
carol 24000
frank 18000

$ awk -F, '$4=="beijing"' users.csv                        # 字符串相等（==）
alice,eng,18000,beijing
carol,eng,24000,beijing

$ awk -F, '/eng/ {print NR": "$0}' users.csv               # 正则匹配整行
2: alice,eng,18000,beijing
4: carol,eng,24000,beijing
5: dave,hr,9000,chengdu      ← 同样是子串问题，但这里可以指定列！
7: frank,eng,18000,shenzhen

$ awk -F, '$2 ~ /^e/ {print $1}' users.csv                 # 正则只作用于某列
$ awk -F, '$2 !~ /eng/ {print $1}' users.csv               # 不匹配
$ awk -F, 'NR==2,NR==4' users.csv                          # 范围模式
$ awk '/bob/,/dave/' users.csv                             # 正则范围
$ awk -F, 'NR%2' users.csv                                 # 奇数行（非 0 即真）
$ awk 'length($0)>60' access.log                           # 只留长行
```

| 运算符 | 说明 |
|--------|------|
| `==` `!=` `<` `<=` `>` `>=` | 比较 |
| `&&` `\|\|` `!` | 逻辑 |
| `~` / `!~` | 匹配 / 不匹配正则 |
| `/re/` | 等价于 `$0 ~ /re/` |
| `?:` | 三元 `$3>=15000 ? "高" : "低"` |
| `in` | `if (key in arr)` |
| `++ -- += -= *= /=` | 与 C 相同 |

### 5.5 统计：BEGIN / END

```bash
$ awk -F, 'NR>1 {s+=$3} END{print "总薪资:", s; print "人数:", NR-1; print "平均:", s/(NR-1)}' users.csv
总薪资: 96000
人数: 6
平均: 16000

$ awk '{s+=$1} END{print "和="s, "行数="NR, "均值="s/NR}' numbers.txt
和=42 行数=7 均值=6

$ awk 'BEGIN{m=-1} {if($1>m) m=$1} END{print "最大:", m}' numbers.txt
最大: 12

# 一次遍历同时算多个指标
$ awk '{s+=$10; if($10>mx)mx=$10; if(mn==""||$10<mn)mn=$10} END{printf "行数=%d 总字节=%d 均值=%.1f 最大=%d 最小=%d\n", NR, s, s/NR, mx, mn}' access.log
行数=10 总字节=16568 均值=1656.8 最大=5321 最小=0
```

要点：awk 的变量**不用声明**，默认是空（数字上下文中当 0），所以 `s+=$3` 第一行也不会报错（见 5.12 的坑）。

### 5.6 数组：awk 的灵魂

awk 的数组全是**关联数组**（哈希表，key 是字符串），这是它比 sed 强一个量级的地方。

```bash
# 分组计数：按城市统计人数
$ awk -F, 'NR>1 {cnt[$4]++} END{for (c in cnt) print c, cnt[c]}' users.csv | sort
beijing 2
chengdu 1
shanghai 2
shenzhen 1

# 分组求和 + 均值（printf 对齐）
$ awk -F, 'NR>1 {sum[$2]+=$3; n[$2]++} END{for (d in sum) printf "%-5s 人数=%d 总额=%d 均值=%.1f\n", d, n[d], sum[d], sum[d]/n[d]}' users.csv | sort
eng   人数=3 总额=60000 均值=20000.0
hr    人数=1 总额=9000 均值=9000.0
ops   人数=2 总额=27000 均值=13500.0

# 日志按 IP 计数并排序（替代 grep|sort|uniq -c）
$ awk '{c[$1]++} END{for (ip in c) printf "%6d  %s\n", c[ip], ip}' access.log | sort -rn
     4  10.0.0.5
     2  192.168.1.20
     2  10.0.0.7
     1  10.0.0.9
     1  10.0.0.11

# 去重（保留首次出现顺序）—— 一行搞定
$ awk '!seen[$0]++' numbers.txt numbers.txt
5
3
9
12

# 二维数组
$ awk '{a[$1","$9]++} END{for (k in a) print k, a[k]}' access.log | head -3
```

> [!tip] `!seen[$0]++` 为什么能去重
> `seen[$0]` 初次访问是 0，`++` 后置返回旧值 0（假），`!0` 为真 → 打印；再次出现时返回 1（真），`!1` 为假 → 不打印。一次遍历、O(1) 判断，比 `sort|uniq` 快且**不乱序**（`sort|uniq` 会排序）。

### 5.7 字符串函数

| 函数 | 作用 | 例子（结果） |
|------|------|-------------|
| `length(s)` | 长度 | `length("abc")` → 3 |
| `substr(s,start[,len])` | 子串（**从 1 开始**） | `substr("alice",1,3)` → `ali` |
| `index(s,t)` | t 在 s 中的位置，无则 0 | `index("hello world","world")` → 7 |
| `split(s,arr[,sep])` | 拆成数组，返回个数 | `split("a:b:c",A,":")` → 3 |
| `sub(re,repl[,s])` | 替换**第一处**（原变量） | |
| `gsub(re,repl[,s])` | 替换**全部**，返回替换次数 | `gsub(/o/,"0",s)` |
| `gensub(re,repl,how[,s])` | 替换并**返回新串**（gawk） | `gensub(/-/,"_","g",s)` |
| `match(s,re)` | 设置 `RSTART`/`RLENGTH`，返回起点 | |
| `toupper` / `tolower` | 转大小写 | |
| `sprintf(fmt,...)` | 格式化**成字符串**（不输出） | `sprintf("%05.2f", 3.14159)` → `03.14` |
| `printf(fmt,...)` | 格式化输出 | |
| `system(cmd)` | 执行 shell 命令 | |
| `close(name)` | 关掉之前打开的管道/文件 | |

```bash
$ awk -F, 'NR>1 {print substr($1,1,3), toupper($2), length($1)}' users.csv
ali ENG 5
bob OPS 3
car ENG 5
dav HR 4
eri OPS 4
fra ENG 5

$ awk 'BEGIN{n=split("a:b:c",arr,":"); for(i=1;i<=n;i++) print i, arr[i]}'
1 a
2 b
3 c

$ awk 'BEGIN{s="hello world"; print index(s,"world"); gsub(/o/,"0",s); print s}'
7
hell0 w0rld

$ awk 'BEGIN{s="a-b-c"; print gensub(/-/,"_","g",s); print gensub(/^(\w+)-/,"[\\1] ","g",s)}'
a_b_c
[a] b-c

$ awk 'BEGIN{s="user=alice"; if (match(s,/=\w+/)) print RSTART, RLENGTH, substr(s,RSTART+1,RLENGTH-1)}'
5 6 alice
```

`sub`/`gsub` 直接改原变量，`gensub` 返回新串（更安全，且支持 `\1` 反向引用）：

```bash
$ awk '{gsub(/errors/,"ERRORS"); print}' f      # 改 $0 并打印
$ awk '{print gsub(/o/,"0"), $0}' f            # gsub 的返回值 = 替换了几处
```

### 5.8 格式化输出 printf

格式串与 C 相同：`%s` 字符串、`%d` 整数、`%f`/`%.2f` 浮点、`%x` 十六进制、`%-10s` 左对齐补空格、`%6.2f` 总宽 6 保留 2 位。

```bash
$ awk -F, 'NR>1 {printf "%-8s %-4s %6d\n", $1, $2, $3}' users.csv
alice    eng   18000
bob      ops   12000
carol    eng   24000
dave     hr     9000
erin     ops   15000
frank    eng   18000
```

> [!warning] `%Ns` 数的是**字符**（或字节），都不是**显示宽度**
> gawk 在 UTF-8 locale 下按字符数补齐（`length("中文") == 2`），`LC_ALL=C` 下按字节数补齐（= 6），而一个汉字占 **2 列**——两种算法都会让含中文的表格错位（实测对比见 8.1）。
> 中文表格改用 **`column -t -c unlimited`**（按显示宽度对齐），或干脆输出 TSV 再喂给 `visidata`。

### 5.9 流程控制与多文件

```bash
$ awk 'BEGIN{for(i=1;i<=3;i++) printf "%d ", i; print ""; i=0; while(i<3) printf "w%d ", ++i; print ""; i=0; do {printf "d%d ", ++i} while(i<2); print ""}'
1 2 3
w1 w2 w3
d1 d2
```

控制语句：`if/else`、`for(;;)`、`while`、`do...while`、`break`、`continue`、`next`、`nextfile`、`exit`。

| 语句 | 作用 |
|------|------|
| `next` | 跳过当前记录的剩余规则，读下一条 |
| `nextfile` | 跳过当前文件的剩余内容，去下一个文件 |
| `exit` / `exit N` | 跳到 END（或直接退出），可设退出码 |

```bash
$ awk -F, '/eng/ {next} {print $1}' users.csv      # 匹配 eng 的行直接跳过
name
bob
erin

$ awk 'FNR==1 {print "== " FILENAME} {nextfile}' access.log users.csv servers.txt
== access.log
== users.csv
== servers.txt

$ awk '{print FILENAME, "NR="NR, "FNR="FNR, $1}' servers.txt numbers.txt | head -4
servers.txt NR=1 FNR=1 web01
servers.txt NR=2 FNR=2 web02
servers.txt NR=3 FNR=3 db01
numbers.txt NR=4 FNR=1 5          ← NR 累加，FNR 每文件重置

$ awk -v lim=15000 -F, 'NR>1 && $3>lim {print $1, $3}' users.csv   # -v 传变量
alice 18000
carol 24000
frank 18000
```

**退出码可用于 shell 判断**：

```bash
$ awk 'BEGIN{exit 3}'; echo "exit=$?"
exit=3
$ awk -F, 'NR>1 && $3>100000 {found=1} END{exit (found?0:1)}' users.csv; echo "exit=$?"
exit=1        # 没有超过 10 万薪资的人
```

**关联两个文件（`NR==FNR` 惯用法）**：

```bash
$ awk 'NR==FNR {svc[$1]=$2; next} {print $1, $2, $3, (svc[$3] ? svc[$3] : "unknown")}' portmap.txt servers.txt
web01 10.0.0.5 22 ssh
web02 10.0.0.7 2222 ssh-alt
db01 10.0.0.20 5432 postgres
```

原理：处理第一个文件时 `NR==FNR` 成立（两者相等），把映射读到数组；`next` 跳过后续规则；到第二个文件时 `NR>FNR`，映射已就绪，做输出。

**跨行状态机**（grep 做不到的事）：

```bash
$ awk '/start/{f=1} f; /end/{f=0}' f        # 打印 start..end 之间的块（含首尾）
$ awk '/BEGIN/{f=1; next} /END/{f=0} f' f   # 打印两标记之间的行（不含标记）
```

### 5.10 gawk 扩展（本机可用，POSIX awk 不一定有）

```bash
$ awk 'BEGIN{n=split("c,a,b",arr,","); asort(arr); for(i=1;i<=n;i++) printf "%s ", arr[i]; print ""}'
a b c
$ gawk --csv 'NR>1{print $4}' users.csv         # CSV 感知
$ awk -v FPAT='([^,]*)|("[^"]+")' '{print $1}' f # 字段用正则描述
$ gawk -i inplace '...' file                     # 原地编辑（见 5.11）
$ awk 'BEGIN{print systime()}'                   # 时间函数
```

> [!note] 其它 awk 实现的差异
> - `mawk`（Debian 默认 `awk`）：快，但没有 `gensub`、`asort`、`FPAT`、`--csv`。
> - `busybox awk`：功能子集。
> - macOS 自带 awk 是 BSD 版，也没有 `gensub`。
> 要写可移植脚本：**只用 POSIX awk 的特性**（`sub/gsub/split/match/substr/index/toupper/tolower/sprintf`），别用 `gensub`/`asort`/`FPAT`。（本机为 gawk，以上均实测可用；其它实现未在本机验证。）

### 5.11 awk 的"原地编辑"

awk 没有 `-i`，三种做法：

```bash
# ① gawk 专属（最干净）
$ gawk -i inplace -F, 'BEGIN{OFS=","} NR>1{$3=$3*1.1} 1' p2.csv

# ② 可移植：临时文件 + mv（推荐）
$ awk -F, 'BEGIN{OFS=","} NR>1{$3=$3*1.1} 1' q.csv > q.tmp && mv q.tmp q.csv

# ③ sponge（moreutils），省掉 tmp 命名 —— 本机未安装，需先装 moreutils
# awk ... q.csv | sponge q.csv
```

注意末尾的 `1`：它是"恒真 pattern + 默认动作 print"的简写，用来**输出所有行**。只写 `{$3=$3*1.1}` 的话，因为赋值不是 pattern，awk 会打印修改后的 `$0`——但一旦你写了任何 action，没被 action 匹配到的行就不会输出，所以显式加 `1` 更安全。

> [!danger] 赋值给字段会重建 `$0`，表头也会被算进去
> ```bash
> $ awk -F, 'BEGIN{OFS=","} {$3=$3*1.1} 1' users.csv | head -2
> name,dept,0,city          ← 表头 "salary"*1.1 = 0，被改坏了
> alice,eng,19800,beijing
> ```
> 所以改列时务必加 `NR>1`。

### 5.12 awk 的坑

**① 数字串 vs 字符串比较（最坑的一个）**

字段看起来是数字，但和**字符串**比较时 awk 会做字符串比较：

```bash
$ printf '10\n9\n' | awk '$1>9 {print $1" > 9 (数值比较)"}'
10 > 9 (数值比较)
$ printf '10\n9\n' | awk '$1>"9" {print $1" > \"9\" (字符串比较)"}'
                        ← 无输出！"10" < "9"
$ printf '10\n9\n' | awk '($1+0)>("9"+0) {print $1}'    # 强制数值
10
```

真实事故（本机复现）：`-v` 传进来的值是**字符串**，跟非数字字段比较会走字符串比较，导致表头被误判：

```bash
$ awk -v lim=15000 -F, '$3>lim {print NR, $1, $3}' users.csv
1 name salary        ← 表头居然"通过"了：字符串 "salary" > "15000"
2 alice 18000
...
$ awk -F, '$3>100000 {found=1} END{exit (found?0:1)}' users.csv; echo exit=$?
exit=0               ← 被表头骗了！以为"存在超过 10 万的人"
$ awk -F, 'NR>1 && $3>100000 {found=1} END{exit (found?0:1)}' users.csv; echo exit=$?
exit=1               ← 正确
```

**防御写法**：① 加 `NR>1` 跳过表头；② 用 `$3+0` / `lim+0` 强制数值；③ 数值比较时不要给比较对象加引号。

**② 未初始化变量同时是 `""` 和 `0`**

```bash
$ awk 'BEGIN{print "x=["x"]", "x+0="x+0, "x==0:", (x==0?"真":"假"), "x==\"\":", (x==""?"真":"假")}'
x=[] x+0=0 x==0: 真 x=="": 真
```

这既是便利（`s+=$3` 不用初始化），也是坑（`mn==""` 判断"还没赋值"和 `mn==0` 无法区分，要单独用标志位）。

**③ `$9==404` 比 `/404/` 慢 70%**——写条件时不必为了"精确"强行拆字段，见第九节实测。

**④ 修改 `$0` 会触发重新分列**：`{$1="IP"}` 会让 `NF` 保持但 `$0` 按 `OFS` 重建。

```bash
$ awk '{$1="IP"; print}' access.log | head -2
IP - - [20/Sep/2026:08:01:11 +0800] "GET /index.html HTTP/1.1" 200 5321
```

**⑤ 单引号是你的朋友**：awk 程序常含 `$`、`"`，一定要用**单引号**包住整个程序，脚本里嵌套时用 `awk '...'` 而非 `"..."`，否则 `$1` 会被 shell 先展开。

## 六、同一个任务的三种写法

**任务 1：取 eng 部门所有人的姓名与薪资**

```bash
# grep + cut（按列取，但 grep 只是粗筛）
grep -F ',eng,' users.csv | cut -d, -f1,3
# alice,18000 / carol,24000 / frank,18000

# sed（正则捕获组）
sed -n 's/^\([^,]*\),eng,\([0-9]*\),.*/\1 \2/p' users.csv
# alice 18000 / carol 24000 / frank 18000

# awk（按字段精确判断，最清晰）
awk -F, '$2=="eng" {print $1, $3}' users.csv
# alice 18000 / carol 24000 / frank 18000
```

三者输出一致，但 grep 的 `,eng,` 依赖"前后有逗号"这种上下文假设，awk 直接说"第 2 列等于 eng"。

**任务 2：统计重复行（numbers.txt = 5 3 9 3 12 5 5）**

```bash
# sort + uniq（会改变顺序）
sort numbers.txt | uniq -c | sort -rn
#       3 5
#       2 3
#       1 9
#       1 12

# awk（保持首次出现顺序，一次遍历）
awk '{c[$0]++} END{for (l in c) print c[l], l}' numbers.txt
```

**任务 3：把每行行首 IP 换成占位符**

```bash
sed -E 's/^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+/IP/' access.log
awk '{$1="IP"; print}' access.log
```

**任务 4：只取 HTTP 状态码一列**

```bash
grep -oP '(?<=HTTP/1.1" )\d{3}' access.log   # 依赖 PCRE
sed -nE 's/.*HTTP\/1.1" ([0-9]{3}).*/\1/p' access.log
awk '{print $9}' access.log                   # 最简单
cut -d' ' -f9 access.log                      # 最快
```

四者输出完全一致（200 200 401 304 …），**能用 cut 的别用另外三个**。

## 七、管道组合实战

```bash
# 出现次数 Top 5 的 IP
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -5

# 5xx 是谁打出来的
$ awk '$9 ~ /^5/ {e[$1]++; where[$1]=where[$1]" "$7} END{for (i in e) print i, e[i], where[i]}' access.log
10.0.0.9 1  /api/orders

# 状态码分布
$ awk '{c[$9]++} END{for (s in c) printf "%s: %d 次\n", s, c[s]}' access.log | sort
200: 6 次
304: 1 次
401: 1 次
404: 1 次
500: 1 次

# 每个 IP 的总流量，按字节降序
$ awk '{b[$1]+=$10} END{for (ip in b) printf "%-15s %8d\n", ip, b[ip]}' access.log | sort -k2 -rn
10.0.0.5           12075
192.168.1.20        2048
10.0.0.9            1024
10.0.0.7             965
10.0.0.11            456

# 两步走：先用 grep 粗筛，再交给 awk 精算（大量数据时更快）
grep -E ' 5[0-9]{2} ' access.log | awk '{print $1, $9, $10}'
10.0.0.9 500 1024

# sed 提取 + sort/uniq 出分布
$ sed -nE 's/.*HTTP\/1.1" ([0-9]{3}) [0-9]+$/\1/p' access.log | sort | uniq -c | sort -rn
      6 200
      1 500
      1 404
      1 401
      1 304

# 系统实战：/etc/passwd 的 shell 分布
$ awk -F: '{c[$7]++} END{for (s in c) printf "%3d  %s\n", c[s], s}' /etc/passwd | sort -rn
  1  /usr/bin/fish
  1  /bin/bash

# 系统实战：UID>=1000 的普通用户及其家目录
$ awk -F: '$3>=1000 && $3<65534 {printf "%-12s %s\n", $1, $6}' /etc/passwd
smile        /var/home/smile
```

> [!tip] 管道的分工原则
> **grep 粗筛负责减少数据量 → awk 精算负责列运算 → sort/uniq 只负责最终排序聚合。**
> 反过来（awk 算完再 grep）通常更慢，因为 awk 已经逐行拆字段了。

## 八、让输出对齐：column

> `column` 不是"第四个剑客"，它只干一件事：**把已经由 grep/sed/awk 摘出来的文本排成对齐的表格**。
> 之所以要单独讲，是因为 `awk printf` **对中文会算错宽度**——它数的是字符数（或 `LC_ALL=C` 下的字节数），两者都不等于**显示宽度**；而 `column` 数的正是显示宽度。
> 本机版本：column from util-linux 2.41.5（/usr/bin/column）。以下均实测。

### 8.1 为什么需要它：awk 对齐中文会错位

```bash
$ cat cjk.txt
aaa bb
中文 bb
中 bb

$ column -t cjk.txt          # 对齐正确
aaa   bb
中文  bb
中    bb

$ awk '{printf "[%-10s][%s]\n", $1, $2}' cjk.txt   # 按"字符数"补 → 中文行反而更宽
[aaa       ][bb]
[中文        ][bb]
[中         ][bb]

$ LC_ALL=C awk '{printf "[%-10s][%s]\n", $1, $2}' cjk.txt   # 按"字节数"补 → 反过来更窄
[aaa       ][bb]
[中文    ][bb]
[中       ][bb]
```

把输出用 Python 按 **East Asian Width** 量一遍，看 `bb` 之前那一整段占了多少显示列：

| 命令 | `bb` 之前的显示宽度 | 结果 |
|------|-------------------|------|
| `column -t` | 6 / 6 / 6 | ✅ 对齐 |
| `awk printf`（UTF-8 locale，本机默认） | 13 / **15** / **14** | ❌ 中文行宽 2 列 |
| `LC_ALL=C awk printf` | 13 / **11** / **12** | ❌ 中文行窄 2 列 |

原因（实测）：

- **gawk 在 UTF-8 locale 下 `%Ns` 数的是字符**：`length("中文")` = **2**，所以补到 10 个字符 = 4 列字 + 8 空格 = 12 列，比 ASCII 行的 10 列多 2 列。
- **加 `LC_ALL=C` 后数的是字节**：`length("中文")` = **6**，只补 4 个空格 = 4 + 4 = 8 列，反过来少 2 列。
- 两种口径**都不是"显示宽度"**——一个汉字占 2 列，而不是 1 字符或 3 字节。所以含 CJK 时 `printf` 无论怎么调 locale 都对不齐。
- **column 数的是显示宽度**：列宽取 `max(3, 4, 2) = 4`，统一补到 4 列再加 2 个空格分隔，所以每行都是 6。

这是 `column` 最常被需要的地方：只要输出里可能出现 CJK/emoji/变音符，`awk printf` 的 `%Ns` 就不再可靠。

### 8.2 三种工作模式

| 模式 | 触发 | 用途 |
|------|------|------|
| 填充模式（默认） | 不加参数 | 把一列清单横向铺成多列，如 `ls \| column` |
| 填行模式 | `-x` / `--fillrows` | 先填满一行再换行 |
| 表格模式 | `-t` / `--table` | 按分隔符切列、对齐 |

```bash
$ printf 'a\nbb\nccc\ndddd\neeeee\nffffff\nggggggg\n' | column -c 40
a	ccc	eeeee	ggggggg      ← 默认用 TAB 分隔（在终端里才看着齐）
bb	dddd	ffffff

$ printf 'a\nbb\nccc\ndddd\neeeee\nffffff\nggggggg\n' | column -c 40 -x
a	bb	ccc	dddd	eeeee    ← -x：先填行再换列
ffffff	ggggggg

$ printf '...' | column -c 40 -S 4      # -S 4：不用 TAB，改用至少 4 个空格
a          ccc        eeeee      ggggggg
bb         dddd       ffffff

$ column -t -x f
column: mutually exclusive arguments: --table --fillrows   # -t 与 -x 不能共用
```

> [!note] `-c` 在填充模式下才是"真正的布局宽度"
> 不写 `-t` 时，`-c 40` 决定了多少列能塞进 40 列；不写 `-c` 则用终端宽度（非交互时 80）。
> `ls | column` 这个 4.3BSD 时代的老用法就是这么来的。

### 8.3 表格模式基础

```bash
$ column -t staff.txt                 # 默认按空白切分
name   dept  salary
alice  eng   18000
carol  eng   24000
bob    ops   12000

$ column -t -s, -c unlimited staff.csv       # -s 指定输入分隔符
name   dept  salary  city      note
alice  eng   18000   beijing   ok
carol  eng   24000   beijing   试用期
bob    ops   12000   shanghai  ok
dave   hr    9000    chengdu   待转岗

$ column -t -s, -c unlimited -o ' | ' -N name,dept,salary,city,note staff.data
name  | dept | salary | city     | note
alice | eng  | 18000  | beijing  | ok
carol | eng  | 24000  | beijing  | 试用期
```

要点：

- **默认输出分隔符是两个空格**，`-o` 可换（本地习惯上加 ` | ` 方便贴进文档）。
- **`-s` 接受的是"可能的分隔符字符集"**，不是完整正则：`-s ',;'` 表示逗号和分号都算分隔符；`-s '::'` 等价于 `-s ':'`。
- **`-s` 自 2.23 起是非贪婪的**：`1::3` 会保留中间的空列，不会把 `::` 折成一个分隔符。

```bash
$ printf 'a:b:c\n1::3\n' | column -t -s ':'
a  b  c
1     3                  ← 空列被保留（旧版会变成 "1  3"）
```

### 8.4 列属性：命名、对齐、隐藏、重排

**列既可以用序号引用（从 1 开始），也可以用 `-N` 起的名字引用**；`0` 表示所有列，`-1` 表示最后一个可见列，`1-5` 表示区间。

```bash
$ column -t -s, -N name,dept,salary,city,note -c unlimited staff.data
name   dept  salary  city      note
alice  eng   18000   beijing   ok
...

$ column -t -s, -N name,dept,salary,city,note -R salary -c unlimited staff.data
name   dept  salary  city      note
alice  eng    18000  beijing   ok      ← 表头也跟着右对齐
carol  eng    24000  beijing   试用期
dave   hr      9000  chengdu   待转岗

$ column -t -s, -N name,dept,salary,city,note -d -c unlimited staff.data
name   dept  salary  city      note      ← -d：-N 只用来引用列，不打印表头
```

**注意**：`-N` 是"**补一行表头**"，不是"声明输入第一行是表头"。所以输入本身已有表头时必须先去掉，否则会出现两行表头：

```bash
$ column -t -s, -N name,dept,salary,city,note -R salary staff.csv   # 输入自带表头
name   dept  salary  city      note
name   dept  salary  city      note    ← 重复了
$ tail -n +2 staff.csv > staff.data      # 正解：先去掉输入表头
```

```bash
$ column -t -s, -H 3,5 -c unlimited staff.data      # -H 隐藏列（序号）
alice  eng  beijing
carol  eng  beijing

$ column -t -s, -N name,dept,salary,city,note -H note -c unlimited staff.data   # 用名字
name   dept  salary  city
alice  eng   18000   beijing

$ column -t -s, -H note staff.data                  # 名字没定义就直接报错
column: undefined column name 'note'                # 退出码 1

$ column -t -s, -O 4,1,3 -c unlimited staff.data    # -O 重排列顺序（不丢列）
beijing   alice  18000  eng  ok
beijing   carol  24000  eng  试用期

$ column -t -s, -l 3 -c unlimited staff.data        # -l 只切 3 列，剩下的全进最后一列
alice  eng  18000,beijing,ok
carol  eng  24000,beijing,试用期
```

| 选项 | 作用 |
|------|------|
| `-N a,b,c` | 定义列名（同时生成表头行） |
| `-d` | 不打印 `-N` 生成的表头 |
| `-R 2,3` / `-R 0` / `-R -1` | 右对齐指定列 / 所有列 / 最后一列 |
| `-H 3,5` / `-H -` | 隐藏列 / 隐藏所有未命名列 |
| `-O 3,1,2` | 调整输出列顺序 |
| `-l 3` | 最多切 3 列，剩余内容进最后一列 |
| `-m` | 拉伸填满可用宽度 |
| `-e` | 每页重复表头（配合分页器才有意义） |

### 8.5 宽度：最容易被坑的地方

规则（实测）：

- 输出宽度预算 = **终端宽度**；**非交互（管道/重定向）时固定 80 列**。
- 内容**默认不截断**，超宽就超宽输出——所以中文表格经常莫名换行/错位。
- `-c 0` 或 `-c unlimited` 关闭限制。**管道里做表格几乎总要加它。**
- 预算不够时，`column` 会借 `-E`（**默认只作用于最后一列**）压缩列宽，代价是长值**溢出、盖住后面的列**。
- `-W` 换行、`-T` 截断都是在预算内完成的，所以它们的效果直接受 `-c` 影响。

```bash
# 默认 80 列预算：-W 会在 ~76 列处折行
$ column -t -s, -W 2 w80.csv
id  desc
1   zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz
    zzzzzzzzzzzzzzzzzzzzzzzz

# -c unlimited：一行到底，不折
$ column -t -s, -W 2 -c unlimited w80.csv
id  desc
1   zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz

# -E：把中间列的"超长值"从宽度计算里剔除
$ column -t -s, e3.csv            # 默认：中间列被 120 字符的长值撞开
k  v                                                                                                                         o
x  qqqqq...（120 个 q）...                                                                                      x
$ column -t -s, -E 2 e3.csv       # 列宽按其余短值算 → 表变窄，但长值会溢出盖住右边的列
k  v                                                                           o
x  qqqqq...（120 个 q，直接压过 o 列的位置）...
```

> [!danger] 管道里一定要 `-c unlimited`
> ```bash
> $ column -t -s, staff.csv          # 输出到管道/文件时按 80 列做预算
> $ column -t -s, -c unlimited staff.csv   # 关掉限制，长行不会被挤变形
> ```
> 这也是 5.8 节说"awk printf 对不齐中文"的完整解法：**别用 printf 硬凑宽度，交给 `column -t -c unlimited`。**

### 8.6 JSON 与树：两个意外好用的功能

**直接输出 JSON**（`-J`，必须配 `-N` 或 `-C`）：

```bash
$ column -t -s, -N name,dept,salary,city,note -J staff.data
{
   "table": [
      {
         "name": "alice",
         "dept": "eng",
         "salary": "18000",
         "city": "beijing",
         "note": "ok"
      },{
         "name": "carol",
         ...
```

```bash
$ column -t -s, -J staff.data
column: option --table-columns or --table-column required for --json   # 不加 -N/-C 直接报错

$ column -t -s, -N name,city -n employees -J ...      # -n 改表名（默认 "table"）
{
   "employees": [
      { "name": "alice", "city": "beijing" ... }
```

默认所有值都是**字符串**；要输出真正的数字/布尔，得用 `-C` 逐列声明（`-C` 与 `-N` 互斥，**必须为每一列都写一个 `-C`**）：

```bash
$ cut -d, -f1,3,5 staff.data | column -t -s, \
    -C name=name -C name=salary,json=number -C name=note -J
{
   "table": [
      {
         "name": "alice",
         "salary": 18000,        ← 没有引号，是真的数字
         "note": "ok"
      },{
```

**树状输出**（`-r` + `-i`/`-p` 给父子关系）：

```bash
$ sed 1d tree.csv | column -t -s, -N id,parent,name -r name -i id -p parent
id  parent  name
1   0       root
2   1       ├─child-a
4   2       │ └─grandchild
3   1       └─child-b
```

> - **纯 ASCII、列数固定、要精确控制**：`awk printf` 就够，还省一个进程。
> - **含中文/emoji、列宽不定、只是想"看着齐"**：`| column -t -c unlimited`，一行解决。
> - **要机器再解析**：别用 column 对齐（它插入的是空格 padding），输出 CSV/TSV 更好。

### 8.8 column 的坑

| 坑 | 现象 | 正解 |
|----|------|------|
| 非交互默认 80 列 | 长行莫名换行/表格被压变形 | 一律加 `-c unlimited` |
| `-N` 会**新增**表头行 | 输入自带表头 → 两行表头 | 先 `tail -n +2`/`sed 1d`，或 `-N` 配 `-d` |
| `-H`/`-R`/`-O` 用名字 | `column: undefined column name 'note'`（退出码 1） | 用序号，或先用 `-N` 定义名字 |
| `-t` 与 `-x` 互斥 | `mutually exclusive arguments: --table --fillrows` | 两个模式分开用 |
| `-J` 没配 `-N`/`-C` | `option --table-columns or --table-column required for --json` | 加 `-N`；要数字类型加 `-C` |
| JSON 全是字符串 | `"salary": "18000"` | `-C name=salary,json=number`（每列都要 `-C`） |
| 空行被吃掉 | 段落结构丢失 | `-L` 保留空行 |
| `-E` 压缩列宽导致错位 | 长值溢出盖住右边的列 | 加 `-c unlimited` 让 `-E` 失效 |
| 佔位符 `-1` 的写法 | `-R=-1` → `column: undefined column name '=-1'` | 短选项跟值用**空格**：`-R -1`、`-H -1` |
| 无效多字节序列 | 原文 `a` + `0xff` + `b` 输出 `a\xffb` | 按 PDF/man 约定编码，属预期行为 |

## 九、性能实测

环境：本机 1000 万行访问日志，455 MB，放在 tmpfs，热缓存；`hyperfine --warmup 1 --runs 4`，**输出写到真实文件**（原因见 3.7 的 `/dev/null` 坑）。所有命令结果一致（都取到第 9 列 / 匹配到同一批行）。

| 命令 | 平均耗时 | 相对基线 |
|------|---------|---------|
| `wc -l big.log`（纯计数基线） | 48.2 ms | 1.0× |
| `LC_ALL=C grep -c 404` | 324.0 ms | 6.7× |
| `grep -F -c 404` | 326.7 ms | 6.8× |
| `grep -c 404` | 333.2 ms | 6.9× |
| `cut -d' ' -f9`（取第 9 列） | 461.2 ms | 9.6× |
| `sed -n '/404/p'` | 617.8 ms | 12.8× |
| `awk '/404/'` | 864.4 ms | 17.9× |
| `awk '$9==404'` | 1471 ms | 30.5× |
| `awk '{print $9}'`（同样取第 9 列） | 1555 ms | 32.3× |

结论与用法建议：

1. **只要"找行"，grep 永远最快**（比 sed 快约 2 倍，比 awk 快约 2.6 倍）。
2. **awk 拆字段很贵**：`$9==404` 比 `/404/` 慢 70%。能先用正则/位置过滤，就别为了"语义清晰"强行按列比较；反过来，如果本来就要按多列算，awk 的拆字段成本是一次性的、值得。
3. **取同一列，`cut` 比 `awk` 快约 3.4 倍**（461 ms vs 1555 ms，两者输出完全相同）：单纯取列用 `cut`。
4. **`LC_ALL=C` 在本机没有加速**（324 ms vs 333 ms，反而略慢；大小写无关匹配时 `grep -ic` 217 ms 反而比 `LC_ALL=C grep -ic` 296 ms 更快）。GNU grep 3.12 对 ASCII 输入已有快速路径，**"加 LC_ALL=C 提速"这条老经验不要无脑照搬**，实际测一下。
5. 关于 `-F`：本机 `grep -F`（326.7 ms）与普通正则（333.2 ms）几乎没有差别，因为模式 `404` 本来就没有元字符。**`-F` 的收益在模式里有 `.` `*` `[` 这类字符时才明显**——但那种情况下更重要的是**正确性**（不会被当正则解析）。

> [!danger] 性能测试的红线
> 别用 `>/dev/null` 重定向做基准测试：GNU grep 检测到 stdout 是 `/dev/null` 时会"命中即退出"，本机实测 `grep -c 404 big.log >/dev/null` 只要 **4 ms**，而真实计数要 **325 ms**——差 80 倍。写文件或用 `wc -l` 收尾。

## 十、坑清单速查

| # | 坑 | 正确做法 |
|---|-----|---------|
| 1 | `grep -c x f >/dev/null` 不会真的计数 | 输出写文件；测性能别丢给 `/dev/null` |
| 2 | `.` `*` `[` `+` `?` 在 BRE 里语义不同 | 需要 `+ ? | () {}` 就用 `-E`（sed 用 `-E`/`-r`） |
| 3 | `/eng/` 匹配子串（`chengdu` 里有 eng） | 按列判断用 `awk -F, '$2=="eng"'` |
| 4 | `sed -i` 换 inode，断硬链接、把软链变普通文件 | 用 `-i.bak`；软链场景用临时文件 + `mv`，或装 moreutils 用 `sponge` |
| 5 | `sed -i .bak`（带空格）= 把 `.bak` 当脚本 | 后缀紧贴：`-i.bak` |
| 6 | `sed 's/.*/x/'` 贪婪吃光整行 | 用 `[^>]*` 限定；或 `awk` 处理 |
| 7 | 替换串里的 `&` 是"整个匹配" | 要字面 `&` 写 `\&` |
| 8 | 多文件时 sed 行号连续、`$` 只指最后一个文件 | 加 `-s` |
| 9 | awk 数字串与字符串比较结果反直觉 | 跳过表头 `NR>1`；`$3+0` 强制数值 |
| 10 | awk 改字段会重建 `$0`，表头被算坏 | 加 `NR>1` |
| 11 | awk `printf "%-8s"` 按字节算宽度，中文错位 | 输出 TSV 或用 `column -t`/`visidata` |
| 12 | `gensub`/`asort`/`FPAT`/`--csv` 是 gawk 扩展 | 可移植脚本只用 POSIX 函数 |
| 13 | 查进程时 grep 匹配到自己 | `ps -ef \| grep '[n]ginx'` |
| 14 | grep 无法跨行匹配 | `awk '/A/{f=1} f&&/B/'`；`pcre2grep -M`（本机未装，需另行安装） |
| 15 | 文件名以 `-` 开头被当选项 | `grep -- pattern ./-file` |
| 16 | `awk '...'` 用双引号包，`$1` 先被 shell 展开 | 永远用单引号 |
| 17 | `column` 非交互时按 80 列做预算，长行被挤变形 | 一律加 `-c unlimited` |
| 18 | `column -N` 是**新增**表头行，不是"声明首行是表头" | 输入自带表头时先 `sed 1d`，或配 `-d` |
| 19 | `column -H/-R/-O` 用名字但没 `-N` | `column: undefined column name '...'`，改用序号或先 `-N` |

### sed

```bash
sed -n '5p' f                  # 第 5 行
sed -n '5,10p' f               # 5-10 行
sed -n '/re/p' f               # 匹配行
sed -n '/re/!p' f              # 不匹配行

sed '3q' f                     # 等效 head -3
```

### awk

```bash
awk '{print $1,$3}' f                 # 取列
awk '{print $NF}' f                   # 最后一列
awk -F, '{print $2}' f                # 逗号分隔
awk 'NR>1' f                          # 去表头
awk '$3>100' f                        # 条件
awk '/re/' f                          # 正则
awk '$2 ~ /^a/' f                     # 指定列正则
awk 'NR==2,NR==5' f                   # 行范围
awk '/a/,/b/' f                       # 模式范围
awk '{s+=$1} END{print s}' f          # 求和
awk '{s+=$1} END{print s/NR}' f       # 均值
awk '{if($1>m)m=$1} END{print m}' f   # 最大值
awk '{c[$1]++} END{for(k in c)print c[k],k}' f     # 分组计数
awk '!seen[$0]++' f                   # 去重（保序）
awk 'FNR==1{print FILENAME}' f1 f2    # 文件名
awk 'NR==FNR{a[$1]=$2;next}{print a[$1]}' m d      # 两文件关联
awk 'BEGIN{OFS=","} {$1=$1} 1' f      # 重新按 OFS 输出
awk '{printf "%-10s%6.2f\n", $1, $2}' f            # 格式化
awk -v x=1 '$1>x' f                   # 传变量
awk 'END{print NR}' f                 # 行数（= wc -l）
awk '{print length($0)}' f            # 每行字节长度
awk 'BEGIN{RS=""} {print NR, NF}' f   # 按段落读
gawk -i inplace '{...}' f             # 原地编辑
```
