# 薄荷输入法（oh-my-rime）使用教程

> 薄荷输入法（oh-my-rime）是一套基于 **Rime** 输入法框架的定制中文输入方案。本笔记基于**本机实际安装的 rime_mint 方案** + 官方文档整理，快捷键和功能以你的实际配置为准。
>
> **方案名**：`rime_mint`（薄荷全拼，`default.yaml` 里 schema_list 第一个）
> **配置目录**：`~/.config/ibus/rime/`
> **官网**：https://www.mintimate.cc/zh/

---

## ✅ 本机环境（已修复 Lua）

今天遇到过一个坑，现已解决，记录在案：
- 之前 `osj` 等 Lua 功能无效，是因为 Fedora 的 `librime` **不带 Lua 插件**，所有 `lua_*` 组件加载失败。
- 已通过 **`rpm-ostree install librime-lua librime-octagram`** 修复（重启后生效）。
- **`librime-lua`**：解决时间/计算器/农历/Emoji 等 Lua 功能。
- **`librime-octagram`**：加载语言模型插件（你那个 400M 的 `.gram`）。

> ⚠️ 现在 Lua 功能应已正常。若日志仍报 `number_translator.lua:64: bad argument ...'modf'`，是「金额大写」脚本的一个小 bug，功能可能受限，需另修。

## 一、方案列表（default.yaml 里有哪些）

可在输入法内切换（`Ctrl+`` 反引号键）：

| 方案 | 说明 |
|------|------|
| **rime_mint** | 薄荷全拼（主方案） |
| **double_pinyin_flypy** | 小鹤双拼 |
| **rime_mint_flypy** | 薄荷拼音-小鹤混输 |
| **terra_pinyin** | 地球拼音-薄荷定制 |
| **wubi98_mint** | 五笔98 |
| **wubi86_jidian** | 五笔86 |
| **t9** | 仓九宫格-全拼 |

> 薄荷的 `default.yaml` 兼容 rimetool，改 `page_size`/键位时**不要改 default.custom.yaml**，直接改方案配置或建 `*.custom.yaml`。

## 二、中英文切换

`ascii_composer` 默认键位：

| 按键 | 行为 |
|------|------|
| **左 Shift** | 提交当前输入并切英文（`commit_code`） |
| **右 Shift** | 临时切英文（`inline_ascii`） |
| **Caps Lock** | 提交当前输入并切英文 |

> 若发现按 Shift 后字母没上屏而是进候选，说明 `switch_key` 设成 `inline_ascii`。可在 `*.custom.yaml` 覆写为 `commit_code` 后重部署。

---

## 三、候选词翻页

| 按键 | 行为 |
|------|------|
| `[` / `]` | 上翻 / 下翻（同时是「以词定字」，见下） |
| `-` / `=` | 上翻 / 下翻 |
| `,` / `.` | 翻页 |
| `Tab` / `Shift+Tab` | 下翻 / 上翻 |
| `Ctrl+v` / `Alt+v` | 下翻 / 上翻 |

> ⚠️ 薄荷默认用 `[`、`]` 做**以词定字**（`select_character`）。想把它们改成纯翻页，需在 `key_binder` 覆写 `select_first_character`/`select_last_character`。

**候选数**：`page_size: 6`（每页 6 候选）。

## 四、全局快捷键

`when` 含义：`has_menu`（有候选时）/ `always`（任意）/ `composing`（组合状态）。

| 快捷键              | 功能                     |
| ---------------- | ---------------------- |
| **Ctrl+` + 反引号** | 切换输入方案                 |
| **Ctrl+Shift+1** | 切简/繁体（`transcription`） |
| **Ctrl+Shift+E** | 切换 Emoji 候选开关          |
| **Ctrl+Shift+2** | 切换中/英文（`ascii_mode`）   |
| **Ctrl+Shift+3** | 全/半角（`full_shape`）     |
| **Ctrl+Shift+4** | 简化字（`simplification`）  |
| **Shift+Space**  | 全/半角                   |
| **Ctrl+period**  | 中/英文标点                 |
| **Ctrl+p/n/b/f** | 组合中上下左右移动              |
| **Ctrl+h/g**     | 退格 / 取消                |

## 六、特殊功能键（Lua，最实用）

> **前提**：已装 `librime-lua`（本机已修复）。这些功能才生效。

### 1. 时间 / 日期 / 星期 / 节气（引导符 `o`）

| 关键词    | 功能    |
| ------ | ----- |
| `osj`  | 时间    |
| `orq`  | 日期    |
| `oxq`  | 星期    |
| `onl`  | 农历    |
| `oww`  | 今年第几周 |
| `ojq`  | 节气    |
| `odt`  | 日期+时间 |
| `ott`  | 时间戳   |
| `ojr`  | 节日    |
| `oday` | 问候模板  |

> 引导符默认 `o`，可改 `key_binder` 的 `shijian_keys`。也可用 `/sj`、`/rq` 等斜杠写法。

### 2. 农历打印 / 转换
- `lunar`：当天转农历
- `N + 数字`：`N20250315`（含年）/ `N0312`（不带年）转农历

### 3. 大写人民币打印
- **`R` + 数字**（如 `R1234.5`）→ 「壹仟贰佰叁拾肆元伍角」
- 小键盘数字无效，用字母上方数字键；方向键/空格选中，`Ctrl+数字` 选

### 4. 简易计算器
- **`=` + 表达式**（如 `=1+2*3`）→ 7
- 关闭：`"recognizer/patterns/expression": ""`

## 八、符号输入（`/` + 关键词，重点）

## 十、中英混合（melt_eng）

- 输入英文直接出英文候选（如 `hello`）

## 十一、Emoji

- `emoji_suggestion` 开关（默认开，`Ctrl+Shift+E` 切换）
- 输入对应拼音出 Emoji 候选，或 `Control+Shift+E` 控制

---

## 十二、语言模型（万象，已配置）

见 [语言模型配置](https://www.mintimate.cc/zh/guide/languageModel.html)，已启用 `wanxiang-lts-zh-hans`（400M，镜像下载）。配置在 `~/.config/ibus/rime/rime_mint.custom.yaml`。

> 模型加载依赖 `librime-octagram` 插件（本机已装）。

---

## 十三、自定义配置（不破坏原文件）

用 `*.custom.yaml` 覆写：

```yaml
patch:
  "recognizer/patterns/expression": ""   # 示例：关闭计算器
  ascii_composer:
    switch_key:
      Shift_R: commit_code
```

---

## 十四、重新部署（让配置生效）

- **方法1**：ibus 托盘 → 右键 → 重新部署
- **方法2**：`pkill -f ibus-engine-rime` 或 `ibus restart`
- 首次加载 400M 语言模型较慢，正常

---

## 十五、常见问题

| 问题 | 解决 |
|------|------|
| `osj` 等 Lua 功能无效 | 装 `librime-lua` + `librime-octagram`（`rpm-ostree install`，重启） |
| 改了配置不生效 | 确认改 `.custom.yaml` 且重新部署 |
| 金额大写报错 | `number_translator.lua:64` modf bug（功能受限，需另修） |
| 输入法没反应 | `ibus restart` |
