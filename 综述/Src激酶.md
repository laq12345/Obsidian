Src 激酶（c-Src）是一类非受体酪氨酸激酶——它是 Src 家族激酶（SFKs：Src、Fyn、Yes、Lyn、Lck 等）的原型成员，因来自鸡肉瘤病毒癌基因 v-src 的细胞同源基因而得名。它锚定在细胞膜内侧（豆蔻酰化修饰），常驻于粘着斑和细胞-细胞连接处，是“力学信号→连接重塑”的关键中介。
它的三个要点
1. 怎么被调控（开关结构）
- 静息态：C 端 Tyr527 被 Csk 磷酸化 → 分子自身折叠成闭合构象（自抑制）
- 激活态：去磷酸化或 SH2/SH3 结构域解离 → 展开 → 激活环 Tyr416 自磷酸化 → 底物磷酸化
- 上游激活它的东西：凝血酶、VEGF、组胺、氧化应激、机械牵张——凡是<mark style="background: #FFB8EBA6;">引起内皮通透性增加的刺激几乎都激活 Src</mark>
1. 它干什么（与本综述直接相关的功能）
- 磷酸化 VE-cadherin（Tyr685/Tyr731 等位点）→ 粘附连接复合体不稳定 → p120-catenin/β-catenin 解离 → VE-cadherin 内吞降解 → 内皮细胞之间“门松了” → 血管通透性增加
- 这就是为什么炎症介质（凝血酶、VEGF）引起肺水肿的核心分子事件之一是 Src 激活；Src 抑制剂（PP2、dasatinib——顺便说，它正是 senolytics D+Q 组合里的 D）在多个模型里减轻血管渗漏
- 此外还参与整合素信号、细胞迁移、增殖存活（PI3K/Akt）
3. 在我们的轴里的角色——Piezo1 双相故事的关键配角（Zhong 2020）
这里有个容易讲反的逻辑，帮你理顺：
生理强度牵张:
  Piezo1 → Ca²⁺ → calpain 激活 → 水解灭活 Src
  → VE-cadherin 磷酸化减少 → 粘附连接稳定 → 屏障保护 ✓

超生理强度牵张:
  Piezo1 过度激活 → Ca²⁺ 超载 → calpain 失控
  → 直接水解 VE-cadherin/β-catenin → 屏障崩塌 ✗
所以在这个语境里 Src 是“破坏者”——它的常规职责就是磷酸化 VE-cadherin 把连接拆开（生理上用于重构、病理上导致渗漏）；而生理水平的 Piezo1 激活反而通过 calpain 把 Src 干掉，等于给连接上了保险。超生理时 calpain 从“灭活 Src 的剪刀”变成“直接剪连接蛋白的剪刀”——量变引起质变，保护机制翻转成破坏机制。
