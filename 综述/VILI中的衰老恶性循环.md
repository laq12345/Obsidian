VILI 中的衰老恶性循环（6 步闭环）
综述里提出的自放大循环：
① 过度牵张 → ROS/DNA 损伤/核力学感知 → 上皮内皮进入衰老
② 亚致死应激的细胞（肺保护通气时代的大多数）→ 衰老 + SASP
③ SASP 招募中性粒细胞/炎症单核 → 更多 ROS/蛋白酶/NETs → 损伤周围细胞
④ 持续 SASP → 局部"炎性衰老"（inflammaging）→ 更多细胞被推入衰老
⑤ 功能性肺泡上皮丢失 + AT2 祖细胞被抑制 → 再生失败
⑥ TGFβ 等 → 成纤维细胞→肌成纤维细胞 → ECM 沉积 → 纤维化
   ↺ 回到③（纤维化又制造力学异常环境 → 更多牵张不均 → 更多衰老）
